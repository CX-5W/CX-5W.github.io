密码学 CTF 知识库

🔐 密码学 CTF 知识库

密码学方向的考点框架与解题速查：编码识别 → 古典密码 → 现代加密 → 非对称攻击。竞赛实战案例见 XCTF 复盘（AES + Feistel + LCG）。

★重点 解密码学题第一步永远是识别：先判断是编码、古典密码还是现代加密，再选择对应攻击手段。

🧭 识别方法论

特征 类型 处理方式
只有 A-Za-z0-9+/=，以 = 结尾 Base64 base64.b64decode() / atob()
只有 0-9a-f，偶数字数 Hex bytes.fromhex() / xxd -r -p
%XX 形式 URL 编码 urllib.parse.unquote()
可见英文字母但读不懂 古典密码 凯撒 → 维吉尼亚 → 栅栏 → 列换位
大量无意义字符/二进制 加密数据 识别算法 → 找密钥 → 解密
固定 32/64 位十六进制串 MD5 / SHA 系列 哈希不可逆，撞库或查彩虹表

完整编码解码方法见 编码解码学习。

🏛 古典密码

密码 原理 破解方法
凯撒 Caesar 字母表整体位移 k 位 暴力遍历 25 种位移 / 词频分析
ROT13 凯撒特例 k=13 再 ROT13 一次即还原
维吉尼亚 Vigenère 多表替换，密钥循环 先 Kasiski 测密钥长度 → 词频破每位移
栅栏 Rail Fence 按行写入按列读取 遍历栏数，看明文可读性
列换位 Columnar 按列写入按密钥列序读 尝试密钥长度排列
培根 Bacon 每组 5 个 A/B 映射字母 提取 A/B 序列按表还原
摩斯 Morse 点划组合 .-.-. 特征明显，空格分隔

🔑 对称加密（AES / DES）

AES 常见模式：

模式 特点 CTF 考点
ECB 相同明文块 → 相同密文块 块重排攻击、模式识别
CBC 每块与前一块异或，需要 IV IV 泄露 / Padding Oracle
CTR 计数器 + 流式加密 已知明文可异或改密文

常见攻击面：

  • 密钥硬编码：脚本里直接写了 key，直接解密
  • IV 复用：相同 IV 导致 CBC 前缀相同
  • Padding Oracle：报错区分填充错误 → 逐字节还原明文

CTF 实战案例：XCTF 站赛 Crypto 题使用 AES-CBC + Feistel 网络 + LCG，核心是从 LCG 输出恢复种子 → 还原 Feistel → 恢复 IV+key → AES 解密。查看完整复盘

🧮 RSA 攻击全家桶

公钥特征：n（大合数）、e（公钥指数）、密文 c。

攻击 条件 思路
共模攻击 同一 n，两个不同 e 扩展欧几里得求系数 → 组合出明文
低指数攻击 e 很小（e=3）且明文短 密文直接开 e 次方
Wiener 攻击 d 很小（d < n^0.25） 连分数逼近 n 的分数展开
p、q 相近 Fermat 分解
已知 p、q 脚本给了分解 直接算 d = inverse(e, φ(n))
低加密指数广播 多组相同 e 不同 n CRT 中国剩余定理

🔄 其他常见考点

  • LCG（线性同余发生器）：X(n+1) = (a·X(n) + c) mod m，给出多组输出可反解参数与种子
  • XOR 爆破：单字节密钥暴力 256 种；多字节密钥用重复密钥 XOR（重合指数测密钥长度）
  • Feistel 网络：分组密码结构，加密流程可逆写解密
  • Hash 长度扩展：MD5/SHA1 的 secret + message 场景可伪造
