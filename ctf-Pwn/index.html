二进制漏洞利用 Pwn

💥 二进制漏洞利用 Pwn

Pwn 是”打二进制程序”：找内存漏洞 → 劫持控制流 → 拿 shell。核心三件套：栈溢出、格式化字符串、堆利用。

★重点 所有利用代码仅在靶机/授权环境测试。

🛡 保护机制速查（checksec）

保护 含义 绕过思路
NX 栈不可执行 ROP 链调用 system
PIE 地址随机化 先泄露地址再计算基址
Canary 栈金丝雀 泄露 canary 或爆破
RELRO GOT 只读 Partial 可改 GOT
Fortify 编译加固 找未加固函数

📚 基础漏洞类型

1. 栈溢出（Stack Overflow）

原理：gets/strcpy 等不检查长度 → 覆盖返回地址。

关键：cyclic(100) 找偏移 → 覆盖返回地址 → 跳转到目标函数/ROP。

2. 格式化字符串（Format String）

原理：printf(user_input) → %n 写任意地址，%x 泄露栈数据。

3. 整数溢出 / 逻辑漏洞

符号问题、长度截断、负数绕过检查，导致越界读写。
