比赛简介

XCTF 网络安全竞赛是国内知名的 CTF 赛事之一，由**攻防世界（AD World）**平台主办，涵盖 Web 渗透、密码学、逆向分析、Pwn 二进制利用等多个方向。本次比赛以个人赛形式进行，考验选手的综合解题能力和临场应变能力。

解题复盘

Web 方向

1. 前端登录绕过

考点：Base64 编码、前端 JavaScript 分析

题目为一个登录页面，用户名固定为 admin，密码在前端通过 JavaScript 进行 Base64 比对验证。

解题思路：

  1. F12 查看页面源码，找到 JS 中的硬编码密码 Q1RGe2Vhc3lfYmFzZTY0fQ==
  2. 识别为 Base64 编码（以 == 结尾，仅含 A-Za-z0-9+/）
  3. 使用 atob() 解码得到明文密码
  4. 输入密码获取 flag

2. User-Agent 绕过

考点：HTTP 请求头修改、Burp Suite 抓包改包

在前端校验的基础上，后端增加了一层 User-Agent 校验，需要将请求头中的 User-Agent 修改为指定值才能通过。

解题思路：

  1. 先用正确的密码通过前端校验
  2. 使用 Burp Suite 拦截提交的 POST 请求
  3. 修改 User-Agent: ctf-show-brower
  4. Forward 放行，获取 flag

3. 多层编码逆向

考点：Base64 多层嵌套、字符串变换逆向

前端 JS 对密码做了 5 层 Base64 编码变换，需要从最外层逐层逆向推导出原始密码。

解题思路：

  1. 从外往内逐层逆向，每层逆向一次 Base64 编码
  2. 处理裁剪操作（.slice(3)、.substr(2)），暴力补全被删除的字符
  3. 使用合法 Base64 字符集作为约束条件缩小搜索范围
  4. 最终还原出原始密码，改包提交获取 flag

详细逆向过程见 ctf-web 题解

密码学方向

编码识别与解码

在密码学题目中，遇到多种编码方式的组合，需要快速识别并解码。

识别流程：

  1. 观察字符集特征（大写字母、数字、特殊符号）
  2. 判断编码类型（Base64 / Base32 / Base58 / Hex 等）
  3. 使用 Python 脚本或 CyberChef 解码

涉及的知识点：

  • Base 家族编码（Base64、Base32、Base58）
  • 古典密码（凯撒、维吉尼亚、栅栏密码）
  • XOR 加解密
  • ASCII / Hex / URL 编码转换
