XCTF 竞赛复盘

百城千赛 · 吉林师范大学站 · 第一名

赛事：百城千赛 · 吉林师范大学站（个人赛）
主办：XCTF 联赛组委会、吉林师范大学
成绩：第一名
时间：2026 年
方向：Web · Crypto · Misc · Reverse

比赛简介

百城千赛是 XCTF 联赛组委会主办的全国性网络安全竞赛系列活动，走进各大高校，旨在挖掘和培养网络安全人才。本次吉林师范大学站比赛在攻防世界（AD World）平台上进行，以个人赛形式展开，共设置 4 道题目，涵盖 Web、Crypto、Misc、Reverse 四个方向，要求选手在限定时间内完成所有题目的解答。

解题复盘

本次比赛共 4 道题，全部独立解出，获得总分第一。

Web

考点：前端 JavaScript 分析、Base64 编码识别与解码

登录页面，密码在前端通过 JS 进行 Base64 比对。查看源码找到密文后使用 atob() 解码即得 flag。

关键点：识别 Base64 编码特征（A-Za-z0-9+/=），在前端代码中找到硬编码的密文字符串。

Crypto（AES + Feistel + LCG）

附件：zes.py（加密脚本）、output（输出结果）

题目实现了一套混合加密方案，使用 AES-CBC 加密 flag，通过 Feistel 网络结构对 IV 和密钥进行多轮加密，并利用线性同余发生器（LCG）生成随机种子。

输出数据：

  • AES-CBC 加密后的 flag 密文
  • LCG 参数（模数、乘数、增量）
  • 20 轮 LCG 输出的高 64 位
  • Feistel 加密后的 IV+key 与 seed 的 XOR 结果

解题思路：从 LCG 输出中恢复种子 → 复原 Feistel 解密流程 → 恢复 IV 和 key → AES-CBC 解密得到 flag

Misc（图片隐写）

附件：secret.png（1.1MB PNG 图片）

通过隐写分析从图片中提取隐藏的 flag 信息。

可能的手法：

  • 图片末尾追加数据（文件缝合）
  • LSB 隐写（最低有效位）
  • EXIF 信息隐藏
  • 通道分离分析

解题思路：使用 binwalk、strings、zsteg 等工具对图片进行全面检查，寻找隐藏数据。

Reverse（ELF 逆向）

附件：46spim（ELF 64-bit 可执行文件）

Linux 平台下的 ELF 二进制文件逆向分析，需要分析程序的执行逻辑并推导出正确的输入或 flag。

解题思路：

  1. 使用 file 命令确认文件类型
  2. 使用 strings 提取可读字符串寻找线索
  3. 使用 IDA Pro 或 Ghidra 进行反汇编分析
  4. 理解程序逻辑后推导出 flag

赛后总结

这次比赛让我在以下几个方面有所提升：

  1. Web 渗透实战能力：从面对登录页面时知道从哪下手，到能系统性地分析前端逻辑和后端校验
  2. 编码分析能力：建立了一套编码识别方法论，不再靠瞎猜
  3. 工具熟练度：Burp Suite 的抓包改包操作达到肌肉记忆水平
  4. Python 脚本能力：赛后编写了自动化解题脚本，沉淀为可复用的工具
