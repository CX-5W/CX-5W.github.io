杂项 Misc CTF

🎲 杂项 Misc

Misc 是 CTF 里最”杂”的方向：图片隐写、文件分析、编码杂项、流量包等。核心能力是工具链 + 细心。

✅ 实战题解：图片隐写（百城千赛 · 吉林师范大学站）

考点：图片隐写分析

附件：secret.png（1.1MB PNG 图片）

解题流程

步骤 操作 工具
① 文件识别 file secret.png 确认真实格式 file
② 字符串提取 strings secret.png | grep -i flag 找明文字符串 strings
③ 文件缝合检测 分离出隐藏的压缩包/文件 binwalk
④ LSB 隐写检测 提取最低有效位数据 zsteg / StegSolve
⑤ 通道分离 RGB 各通道独立查看 StegSolve
⑥ EXIF 检查 元数据里藏信息 exiftool

工具速查

拿到图片先跑一遍上面的工具链，90% 的图片隐写题都能定位到藏匿点。

🧰 Misc 知识框架

考点 特征 处理方法
文件缝合 文件尾部有多余数据 binwalk 检测 + dd 分离
LSB 隐写 像素最低位被改动 zsteg / StegSolve / Python 提取
图片宽高改过 CRC 报错 / 显示异常 PNG IHDR 修复宽高
GIF 帧分离 多帧动画 逐帧提取找 flag
压缩包伪加密 打开提示加密但无密码 ZIP 加密位修复 / 爆破
二维码 图像中藏二维码 裁剪增强后扫描
音频隐写 WAV 频谱异常 Audacity 频谱图 / SSTV 解码
内存取证 拿到镜像文件 volatility 分析进程/文件
