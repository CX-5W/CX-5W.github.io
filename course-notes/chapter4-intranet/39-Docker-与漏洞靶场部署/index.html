39 · Docker 与漏洞靶场部署

Docker 与漏洞靶场部署

⭐ 一句话总结:Docker 把”装好的软件”打包成小体积镜像,一条命令就能运行;配合 docker compose 和 Vulhub,几分钟就能搭出任意漏洞环境做漏洞复现。

学习目标

  • 理解镜像、容器、仓库三个核心概念
  • 会安装 Docker 并掌握常用镜像/容器命令
  • 会用 docker compose 一键启动多容器项目
  • 会用 Vulhub 搭建漏洞靶场并复现漏洞

一、Docker 是什么

  • 2013 年诞生的容器化技术:把软件连同运行环境打包成”镜像”,别人拉下来直接运行。
  • 对比虚拟机:虚拟机打包整个操作系统(十几~20G),镜像只有软件本身(Nginx 约 200M),体积小、传输快、复用性强。
  • 架构:C/S 模式,docker 命令是客户端,daemon 是服务端。
概念 说明
镜像 image 安装好软件的”压缩包”,只读模板
容器 container 镜像运行起来的实例(相当于一个微型虚拟机)
仓库 存镜像的地方,公共仓库 Docker Hub(hub.docker.com)

二、安装 Docker

  • CentOS/RedHat 系用 yum install docker。
  • 下载慢时配置国内镜像源:/etc/docker/daemon.json 写入 Docker 中国镜像/清华/阿里源,重启生效。

三、镜像操作

  • 官方镜像名简短(nginx);用户上传的带用户名前缀(jadon/nginx)。
  • 用 镜像名:版本 打包导出,别人 load 后才有名称和版本;用 image ID 打包会丢失名称。
  • 指定版本可能因仓库问题拉不到对应版本,可去 hub.docker.com 的 tags 页确认。

四、容器操作

  • 端口映射:容器有自己的内网 IP(172.17.0.x),浏览器访问宿主机 IP:端口,数据转发到容器内部端口。
  • 重启 docker 服务后普通容器会停止,只有 --restart=always 的会自动拉起。
  • -e 设置环境变量,如 -e MYSQL_ROOT_PASSWORD=123456。

五、docker compose 批量管理

用 yml 文件描述多个容器,一条命令全部启动。

  • yml 语法:严格缩进,只能用空格,不能用 Tab。
  • 文件名固定为 docker-compose.yml / docker-compose.yaml。
  • 示例:一条命令同时启动 MySQL+WordPress,浏览器访问 IP:83 完成安装。

六、Vulhub 漏洞靶场

  • Vulhub = Vulnerability(漏洞)+ Hub(仓库),开源的漏洞复现环境集合,每个漏洞一个目录。
  • 使用流程:
  • 启动失败常见原因:网络拉不到镜像、端口冲突(先停掉其他容器)。
  • 漏洞复现 = 搭建和线上相同版本的环境 → 用攻击载荷打进去 → 证明漏洞真实存在(如拿到敏感信息/控制服务器)。

七、实例:Nginx 解析漏洞 + 图片马

  1. 制作”图片马”:图片文件末尾拼接 PHP 代码,如 <?=phpinfo();?>。
  2. 上传图片马后访问 shell.png/.php。
  3. 由于 Nginx 配置问题(cgi.fix_pathinfo=1),服务器把图片按 PHP 解析,图片里的代码被执行。
  4. 执行 phpinfo 只是信息泄露;若换成 system() 命令,直接控制服务器。

⭐ 重点:漏洞复现流程 = 找环境 → 搭环境 → 上传载荷 → 验证利用 → 查配置找根因;这就是后面做漏洞检测的标准思路。

八、重点速记

  • 镜像=模板、容器=运行实例、仓库=Docker Hub
  • search/pull/run/rmi/save/load/push/commit
  • 容器参数:-d -p –name -it -e –restart=always
  • compose 用 yml 管理多容器;up 启动、down 停止
  • Vulhub 每个漏洞一个目录,docker compose up -d 秒搭靶场
  • Nginx 解析漏洞:cgi.fix_pathinfo=1 + 图片马 → 代码执行

自测题

  1. 镜像、容器、仓库分别是什么?
  2. docker pull 和 docker run 的区别?
  3. -p 8080:80 是什么意思?
  4. –restart=always 有什么用?
  5. docker save 和 docker load 干什么?
  6. docker compose 的配置文件有什么语法要求?
  7. Vulhub 是干什么的?怎么启动一个漏洞环境?
  8. Nginx 解析漏洞是怎么利用图片马的?
参考答案 1. 镜像是被打包好的软件模板,容器是镜像运行后的实例,仓库是存放镜像的地方。
2. pull 只下载,run 下载并运行。
3. 把宿主机 8080 端口映射到容器 80 端口。
4. 容器开机或 docker 重启后自动启动。
5. save 导出镜像为文件,load 从文件导入镜像。
6. 严格缩进、只能用空格、文件名 docker-compose.yml。
7. 开源漏洞复现环境集合;进入漏洞目录执行 docker compose up -d。
8. 图片里拼 PHP 代码,利用 cgi.fix_pathinfo=1 让 Nginx 把图片当 PHP 解析执行。
