38 · 渗透系统安装与靶场部署

渗透系统安装与靶场部署

⭐ 一句话总结:渗透测试前先准备”练兵场”——装好 Win2003/2008/Win7/Win10/Kali 虚拟机,再用 PHPStudy、IIS、Tomcat/JBoss 搭建 PHP、ASP、JSP 三类靶场,之后所有漏洞实验都在自己环境里做。

学习目标

  • 会做杀毒软件免杀设置和虚拟机快照
  • 能按步骤装出 Win2003/2008、Win7、Win10、Kali
  • 用 PHPStudy 部署 BWAPP、皮卡丘、V-Bug 等 PHP 靶场
  • 用 IIS 部署 ASP/ASP.NET 靶场
  • 用 Tomcat+Struts2、JBoss 部署 JSP 靶场
  • 会使用渗透工具包并理解 WebShell 的危害

一、前置准备

  • 免杀设置:Windows Defender 会静默删除安全工具,先到”病毒和威胁防护→管理设置→添加排除项”,把工具盘/文件夹加为排除项,再把下载的镜像和工具放进去。
  • 虚拟机软件:VMware Workstation(建议 16.2.2,与课程一致);Mac 可用 VMware Fusion/PD。
  • 磁盘规划:所有 ISO 镜像和虚拟机放一个独立大分区(建议 1T 左右),并做免杀。
  • 课程提供的虚拟机压缩包:解压后打开 .vmx 文件 → 提示”我已复制该虚拟机” → 开机直接用,省去自己安装。

二、要准备的系统

Win2003、Windows Server 2008、Win7、Win10、Kali 2022/2023,全部用桥接模式(和物理机同网段,方便互相访问)。

三、安装要点(常见坑)

系统 关键步骤 / 坑
Win2003 32 位企业版;40G 单文件;1CPU/2G;桥接;装 VMware Tools 前先装补丁
Server2008 装补丁+VM Tools;用共享文件夹传文件;拍快照前先关机
Win7 64 位旗舰版;普通用户 jadon 登录后激活 administrator;关闭自动休眠
Win10 16.2.2 默认 UEFI 引导会蓝屏,需关机后改固件为 BIOS;关闭自动更新和杀软;加 60G 硬盘并分区为 GPT,得到 E 盘
Kali 默认 root/123;Xshell 不能直接 root 登录,先用普通用户再 su - 切换
  • 共享文件夹:物理机右键文件夹→属性→共享→Everyone+读取/写入;虚拟机用 \\物理机IP\共享名 访问,输入物理机用户密码。
  • 坑:两台主机用户名相同但密码不同会直接报错,不会弹窗;连续输错 3 次用户会被锁定。
  • 快照:关机后再拍,又快又稳;拍完可随时”玩坏了恢复”。

四、靶场概念

  • 没有授权不能测别人网站,所以要自己搭靶场练手。
  • 靶场 = 有漏洞的网站/系统环境,覆盖 PHP、ASP/ASP.NET、JSP 等语言。

五、PHP 靶场(PHPStudy)

  • PHPStudy 2018:一键集成 Apache/Nginx、MySQL,站点根目录为 www。
  • 默认文档按顺序找 index.html/index.php/1.php;1.php 是探针文件(phpinfo),能收集服务器版本、路径、配置——线上网站有探针等于裸奔。
  • 数据库:root/root;命令行入口:PHPStudy→MySQL 工具→命令行。

BWAPP 部署

  1. 解压后把真实站点目录(含 index.php 的那层)放到 www/bwapp。
  2. 数据库配置在 admin/settings.php(root/root),数据库名 bwapp。
  3. 访问 /bwapp/install.php 自动建库建表,比手工建库更稳妥。
  4. 默认账号 bee / bug。

皮卡丘(Pikachu)

  • 著名 PHP 靶场,解压后放到 www,访问 IP 即可。

V-Bug 综合靶场

  • 内置 16 关基础挑战+进阶/实战,还打包了 22 个 CMS 站点和数据库。
  • 站点用 PHP 版本不同,报错时切换 PHPStudy 的 PHP 版本即可。

六、ASP/ASP.NET 靶场(IIS)

  • IIS 是 Windows 自带的 Web 服务器,控制面板→添加/删除程序→添加组件→应用程序服务器→勾选 ASP.NET 安装。
  • 装完后在”Web 服务扩展”里把 ASP 设为允许,否则无法解析 ASP。
  • 默认站点根目录 C:\Inetpub\wwwroot;默认文档(Default.htm、index.asp 等)按顺序匹配。
  • 新建网站可分别指定 IP、端口、主机头(域名),实现多站点;没默认文档时开启”目录浏览”可列出目录。
  • 主机头演示:网站属性→网站→高级→添加 域名;再改本机 hosts 文件加 IP 域名 才能访问,否则 400。
  • 部署 ASP 网站常需:添加默认文档 index.asp、勾选”启用父路径”(允许 ../)、匿名访问、目录安全性可做 Basic 认证。
  • ASP.NET 网站需要 .NET Framework 4.0 + SQL Server,网站属性里把 ASP.NET 版本选为 4.0。
  • IIS 也可以配置重定向、端口等,和 Nginx/Apache 功能对应,只是图形化操作。

七、JSP 靶场(Tomcat/JBoss)

Tomcat + Struts2

  • Struts2 是 Java 的 MVC 框架(公用代码集合),用 JSPStudy 一键装 Tomcat。
  • 把 xxx.war 放进 tomcat/webapps 自动解压部署,访问 /s2。
  • Struts2 站点路径常以 .action / .do 结尾;框架漏洞影响面大,是企业 Java 站重点目标。

JBoss

  • Red Hat 出的 Java Web 服务器,无集成环境,需手动装 JDK6 并配环境变量(JAVA_HOME、classpath、PATH),再加 JBOSS_HOME、system root。
  • 启动 bin/run.bat,默认 8080;要允许外部访问需改配置文件 deploy/jboss-web.deployer/server.xml 的 bind address 为 0.0.0.0。
  • 默认后台弱口令 admin/admin——弱口令漏洞的典型例子。

八、Win10 渗透工具包

  • 装 64 位 WinRAR 解压;把 we start 工具包解压到 E 盘(已免杀)。
  • 工具运行常缺 .NET Framework 3.5:离线安装用 DISM 命令指定 ISO 镜像盘符即可。
  • K8 Struts2 综合漏洞利用工具:输入目标 URL → 获取信息 → 执行命令(whoami、net user),演示如何通过框架漏洞拿下服务器。

⭐ 重点:WebShell(如 PHP 一句话木马)就是能执行命令的网页后门,拿到它等于控制服务器;靶场里玩可以,千万别对未授权目标动手。

九、重点速记

  • 免杀排除项→防杀软删工具;快照关机拍
  • 桥接模式让虚拟机与物理机互通;共享文件夹传文件
  • PHPStudy=Apache/Nginx+MySQL;BWAPP 默认 bee/bug
  • IIS 需开 ASP 扩展、默认文档、父路径;ASP.NET 需 .NET4+SQLServer
  • JSP 靶场:Tomcat 放 war 包;JBoss 改 bind 0.0.0.0,弱口令 admin/admin
  • WebShell 可控制服务器,只允许在自己靶场使用

自测题

  1. 为什么要做免杀(排除项)设置?
  2. 快照在什么时候拍更快?
  3. Win10 虚拟机蓝屏进不了安装界面怎么办?
  4. 共享文件夹连接报”用户名或密码错误”的常见原因?
  5. BWAPP 部署时数据库配置改哪个文件?
  6. IIS 部署 ASP 站点必须开启什么?
  7. Tomcat 部署 war 包放到哪个目录?
  8. WebShell 是什么?有什么危害?
参考答案 1. 防止 Windows Defender 静默删除安全工具和木马样本。
2. 关机后拍,速度快且状态干净。
3. 关机后在虚拟机设置→选项里把固件从 UEFI 改成 BIOS 再启动。
4. 两台主机用户名相同但密码不同,系统直接用本机密码尝试导致报错。
5. admin 目录下的 settings.php。
6. Web 服务扩展中允许 ASP,并配置默认文档。
7. tomcat 的 webapps 目录,war 包会自动解压。
8. 能执行系统命令的网页后门,可控制服务器,只能用于授权测试。
