65 · 权限提升

权限提升

⭐ 一句话总结:拿到 WebShell 通常只是普通用户权限,提权就是把它升到管理员/root/system;途径有系统漏洞、MSF、内核漏洞、数据库(UDF/MOF/启动项)等,提权后最好用反弹 Shell 保持长连接。

学习目标

  • 理解提权概念与前提
  • 掌握 Windows/Linux 提权
  • 掌握数据库提权(UDF/MOF/启动项/MSSQL)
  • 理解反弹 Shell 的重要性

一、提权概念

  • WebShell 权限 = 网站部署用户权限(普通用户),很多操作做不了。
  • 目标:提升到 administrator/system(Windows)、root(Linux)。
  • 链条:WebShell → 提权 → 权限维持 → 内网渗透。

二、Windows 提权

1. 系统漏洞 EXP

  • 查看版本/补丁(systeminfo),到漏洞库/Exploit-DB 找对应 EXP。

2. SC 创建服务提权

  • 用低权限创建系统服务指向自己的程序,启动后以 SYSTEM 运行。

3. MSF 提权

  • 先 ps 找到以 SYSTEM 运行的进程,再 migrate 其 PID。

一句话木马原理

  • 连接密码 = POST 参数名,木马用 eval($_POST['密码']) 执行指令。
  • WebShell 每次请求都重新走 Web 服务低权限,提权结果无法保持 → 必须反弹 Shell。

三、Linux 提权

1. 内核漏洞(脏牛 DirtyCow)

2. sudo 提权

  • sudo -l 查看当前用户可用 sudo 命令,找可提权的程序。

3. SUID 提权

  • find / -perm -4000 找 SUID 程序,利用可写脚本/程序提权。

四、数据库提权

1. MySQL UDF 提权

  • 前提:拿到数据库连接密码(看网站配置文件/下载 mysql.user 表撞库)。
  • 授权 root 远程连接:
  • 上传 UDF 插件(DLL),创建自定义函数(如 sys_eval),通过函数执行系统命令添加用户。

2. MySQL MOF 提权(Windows)

  • 利用 WMI 每分钟执行 MOF 的特性,写入创建用户的 VBS/MOF,自动提权。
  • 删除后还会再生:需停服务、删目录再重启。

3. MySQL 启动项提权

  • 建表插入 VBS 脚本(创建用户+加入管理员组),select ... into outfile 写到启动文件夹。
  • 服务器重启后自动执行,创建用户成功。

4. MSSQL 提权

  • SA 默认允许远程连接 → 爆破 SA 弱口令。
  • 连接后开启 xp_cmdshell 执行系统命令:

5. Oracle

  • 超级管理员 DBA;工具 OracleShell,可执行命令/文件管理。

五、反弹 Shell

  • WebShell 无状态、权限低;反弹 Shell 是长连接,提权后直接可用高权限。
  • 方式:MSF/CS 木马、NC 监听、WebShell 内置反弹功能。

六、重点速记

  • 提权目标:普通用户→管理员/root/system
  • Windows:漏洞EXP、SC服务、MSF getsystem/migrate
  • Linux:脏牛、sudo、SUID;searchsploit 找EXP
  • MySQL:UDF、MOF、启动项
  • MSSQL:SA爆破+xp_cmdshell
  • 反弹Shell:长连接,提权结果可保持

参考答案 1. WebShell继承网站部署用户的权限,一般是普通用户。
2. getsystem 和 migrate 进程迁移。
3. 利用Linux内核漏洞创建等于root权限的用户(如firefart)。
4. sudo -l。
5. 拿到数据库连接账号密码,并支持写入插件目录。
6. 默认不允许远程;grant授权root@%并flush privileges。
7. Windows WMI每分钟执行MOF文件的特性。
8. 把创建用户的脚本写入启动文件夹,重启自动执行。
9. xp_cmdshell执行系统命令。
10. WebShell每次请求都是低权限,长连接才能保持提权结果。
