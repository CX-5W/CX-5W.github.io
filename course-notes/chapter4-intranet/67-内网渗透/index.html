内网渗透

⭐ 一句话总结:拿下公网主机后先做信息收集,再提权和权限维持,最后通过 Socks 代理/端口转发/隧道打通”不出网”的内网主机,扩大战果。

学习目标

  • 理解内网/外网/局域网概念
  • 掌握拿下主机后的信息收集项
  • 掌握权限维持手段
  • 会用端口转发、reGeorg、EW 做内网渗透

一、概念

  • 外网主机:有公网 IP、可出网。
  • 内网主机:无公网 IP、不可出网,只能内网访问(数据库/文件/后台系统等)。
  • 局域网 = 内网环境;出网与否是相对概念。
  • 不出网主机 → 用 Socks 代理/端口转发/隧道打通数据。

三、信息收集项

项 内容
系统版本/补丁 systeminfo、uname -a;找 EXP
Shell 权限 普通权限→提权
用户/用户组 找管理员组用户,为后续收集密码/登录做准备
杀毒软件 判断是否需要免杀(服务器一般少装)
防火墙 进站/出站规则,决定端口能否使用
端口/服务 判断应用,配合提权
域信息 工作组/域组织形式

四、权限维持

  • 创建用户(容易被巡检发现)
  • 利用现有用户(收集管理员密码,mimikatz)
  • 计划任务(定时下载运行木马)
  • 服务(SC create)
  • 启动项/注册表
  • 映像劫持(屏蔽杀软)
  • 篡改常用工具文件(如 ps)

五、内网渗透工具分类

类型 工具 说明
端口转发 NC、LCX、netsh 把内网端口数据转出来
HTTP 隧道 reGeorg + ProxyFire 利用已上线主机的 Web 建立隧道
Socks 代理 EW(earthworm)、SocksCap、Proxychains 打通不出网主机

六、端口转发(LCX)

  • 转出什么端口的数据,就用对应工具接收(3389→远程桌面)。

七、reGeorg HTTP 隧道

  1. 上传 tunnel.php 到已上线主机 Web 目录。
  2. 攻击机运行 reGeorg.py -p 999 -u http://目标/tunnel.php,监听本地 999。
  3. 用 ProxyFire 把本机程序(浏览器)代理到 127.0.0.1:999(Socks5)。
  4. 浏览器访问内网 IP,数据经 HTTP 隧道转发。

九、隐藏自己

  • 使用国外 VPS + VPN 中转,蓝队溯源难追到本人。

十、流量特征

  • 菜刀:base64 特征
  • 冰蝎:AES+base64、密钥协商
  • 蚁剑:UA=antSword
  • 哥斯拉:AES 加密
  • EW/reGeorg 等也有固定流量特征;使用前需修改防检测。

十一、重点速记

  • 外网可出网,内网不出网;代理解决不出网
  • 流程:信息收集→提权→权限维持→内网渗透
  • 权限维持:用户/计划任务/服务/启动项/映像劫持
  • 端口转发:LCX/netsh;隧道:reGeorg;代理:EW/SocksCap
  • 隐藏身份:VPS+VPN
  • 工具流量特征要改

参考答案 1. 外网有公网IP可出网,内网无公网IP不可出网。
2. 通过代理/端口转发/隧道。
3. 信息收集。
4. 系统版本补丁、权限、用户组、杀软、防火墙、端口服务、域信息。
5. 用户、计划任务、服务、启动项、映像劫持等。
6. 目标主机slave转发端口到攻击机监听端口,攻击机再转本地用对应工具连接。
7. 上传tunnel.php→运行reGeorg.py监听→ProxyFire配Socks5代理浏览器。
8. 正向由攻击机主动连,反向由目标机主动连攻击机。
9. 隐藏真实IP,防溯源反制。
10. 菜刀base64、冰蝎AES+base64、蚁剑UA特征、哥斯拉AES。
