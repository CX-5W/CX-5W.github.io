71 · 内网穿透与域渗透基础

内网穿透与域渗透基础

⭐ 一句话总结:内网渗透分局域网攻击、内网穿透、域渗透三块;内网穿透用”代理”把数据转出来,数据被过滤时再用”隧道”换一种协议(ICMP/DNS)绕过;域则用域控(AD)统一管理和统一认证,拿不到域控前先靠 mimikatz 收集口令做横向尝试。

学习目标

  • 区分局域网渗透、内网穿透、域渗透
  • 掌握代理(ngrok/FRP/NPS/Socks)与隧道(ICMP/DNS)的原理
  • 理解工作组与域的区别、AD/域控/域树/域森林概念
  • 掌握域内信息收集与口令传递基础思路

一、内网渗透三大块

模块 常见手段 特点
局域网渗透 ARP 欺骗 内容少,面试问得少
内网穿透 代理、隧道 每家公司都有内网,必问
域渗透 域信息收集、口令传递、黄金票据等 环境不一定有,优先级稍低

二、代理 vs 隧道

两者都解决”内网主机数据转出/通信”问题,区别在于:

  • 代理:直接把数据转发出来(如 Socks 代理),不改变数据协议。
  • 隧道:在代理基础上再加一层协议转换,把原协议(如 TCP)数据伪装成防火墙放行的协议(如 ICMP、DNS)再传出来。

三、内网穿透工具

ngrok(实验用)

  • 使用国外第三方服务器中转,把攻击机内网 IP 映射到公网。
  • 流程:注册 → 开通隧道(付费 2 元)→ 拿到公网地址 → 下载客户端 → ./sunny clientid <隧道ID> → 看到 online 即成功。
  • 生成木马时把 payload 的 lhost 指向公网地址(80 映射到攻击机 44 端口),攻击机用 MSF 监听 44 端口。
  • 缺点:数据经过第三方服务器,成果可能被截留,且国外服务器不稳定,实战很少用。

FRP(实战最常用)

  • 自建服务器(如阿里云),Go 语言编写,分服务端 frps 和客户端 frpc。
  • 核心配置:
  • 流程:上传 frps 到云服务器 → 改端口 → 加执行权限 chmod +x → 运行 ./frps -c frps.ini → 云安全组放行 6677(通信)和 6000(数据端口)→ 攻击机运行 ./frpc -c frpc.ini。
  • 木马 lhost 填云服务器公网 IP、端口填 remote_port(6000);目标机访问的是公网 IP:6000,数据经云服务器转发到攻击机。

NPS

  • 与 FRP 类似,也是自建服务器做内网穿透;FRP 使用者更多。

Socks 代理

  • 适用于目标完全不能上网的纯内网主机;常用工具:EW、毒液、frp 的 socks5 插件、CS 代理。

四、隧道技术

按 OSI 分层,常见隧道:

层级 隧道示例
网络层 IPv6 隧道、ICMP 隧道
传输层 TCP/UDP 端口转发(LCX、NC)
应用层 SSH/HTTP/HTTPS 隧道、DNS 隧道

实战最常用 ICMP 隧道和 DNS 隧道,因为防火墙很少封 ping 和 DNS 查询。

ICMP 隧道示例(把 TCP 伪装成 ICMP)

DNS 隧道

  • 用 CS 即可实现:在域名服务商配置 A 记录(公网服务器)+ 两条 NS 记录;服务器开放 53 端口。
  • CS 服务端部署在云服务器,客户端连接后新建 DNS 监听器,把 NS 记录填进去。
  • 生成的木马在目标机以 DNS 查询的方式把数据带出来,防火墙几乎不拦。

五、工作组与域

工作组

  • 只是给计算机分组(如 sales、finance),Windows 默认都在 WORKGROUP。
  • 缺点:不能统一管理(软件要逐台装),不能统一身份认证(访问每台共享都要输用户名密码)。

域

  • 解决统一管理与统一认证:域控下发组策略,所有成员机自动执行;域用户登录一次即可访问授权资源。
  • 关键概念:
概念 说明
DC(域控) Domain Controller,域的管理者,像”大脑”
AD(活动目录) 装在 DC 上,存储域用户、计算机、组策略等信息
根域 域树的顶级域名(如 test.com)
域树 只有一个根域,下挂多个子域
域森林 多个根域互相建立信任关系的集合
  • 域内主机用域名(二级/三级域名)标识,成员机 DNS 指向 DC。
  • 拿下 DC = 拿下整个域;所以域渗透的核心是定位并拿下域控。

六、域内信息收集

口令收集

工具 说明
mimikatz Windows 下最常用,需管理员权限(privilege::debug);sekurlsa::logonpasswords 抓内存口令哈希/明文
ladon 集成信息收集与爆破,功能多
收费国外工具 可收集登录过的网站密码,需梯子

提示:拿到本机密码不能只用于本机——管理员常多处复用密码,把密码当字典去撞域内其他主机,逐步接近域控。

存活/端口探测

  • 系统自带 ping 写 PowerShell for 循环,最稳且免杀。
  • NBTscan:老牌存活探测工具,能直接标出 DC。
  • Nishang:PowerShell 脚本,系统自带执行环境、免杀,可执行 Get-Information、端口扫描等。
  • Nmap 功能强,但上传后容易被杀软干掉,内网探测常优先用系统命令。

七、口令传递攻击

明文口令传递(IPC$)

  • IPC$ 命名管道,访问共享资源用,走 135/139/445 端口。
  • 流程:用已知用户名密码建立 IPC$ 连接 → 上传木马文件 → 添加计划任务执行 → 建立控制/添加用户。

计划任务创建(2012 分水岭)

  • Windows Server 2012 之前:用 at。
  • Windows Server 2012 及以后:用 schtasks。

八、重点速记

  • 内网渗透:局域网(ARP)、内网穿透、域渗透
  • 代理转发不换协议;隧道 = 代理 + 协议转换
  • 能上网 → ngrok/FRP/NPS;纯内网 → Socks;TCP 被过滤 → ICMP/DNS 隧道
  • 实战多用 FRP(自建服务器,数据不外泄);隧道常用 ICMP 和 DNS
  • 工作组只有分组;域 = 统一管理 + 统一认证
  • DC 装 AD,域内大脑;拿下 DC 拿下全域
  • mimikatz 抓口令 → 密码复用 → 撞其他主机 → 接近域控
  • 明文口令走 IPC$;2012 前后计划任务命令不同

参考答案 1. 局域网渗透、内网穿透、域渗透。
2. 代理只转发数据;隧道在代理基础上把数据换成另一种协议绕过过滤。
3. 能上网用 ngrok/FRP/NPS;完全不出网用 Socks 代理(EW、毒液)。
4. ngrok 用国外第三方服务器,FRP 自建服务器,数据更安全。
5. IPv6/ICMP、TCP/UDP 端口转发、SSH/HTTP/HTTPS/DNS;因为防火墙很少封 ping 和 DNS 查询。
6. 目标主机 TCP 出口被防火墙限制,但 ICMP 放行时,把 3389 等 TCP 数据伪装成 ICMP 转出。
7. 统一管理和统一身份认证。
8. DC 是域控主机;AD 是装在 DC 上存储域信息的活动目录;域树只有一个根域;域森林是多个根域建立信任的集合。
9. 管理员权限(privilege::debug);sekurlsa::logonpasswords。
10. 管理员常复用相同密码,可用收集到的密码尝试登录域内其他主机。
11. IPC$ 命名管道;走 135/139/445 端口。
12. 2012 之前用 at,2012 及以后用 schtasks。
