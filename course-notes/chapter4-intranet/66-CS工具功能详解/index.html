CS 工具功能详解

⭐ 一句话总结:Cobalt Strike(CS)是红队/APT 的”作战平台”:生成木马让主机上线,集成了钓鱼、凭据导出、Socks 代理、会话转移、权限维持等功能,可多人与服务端协同攻击。

学习目标

  • 理解 CS 架构与监听器
  • 会生成木马让主机上线
  • 掌握 CS+MSF 会话互转
  • 掌握钓鱼、克隆网站、邮件钓鱼
  • 理解 Socks 代理内网渗透
  • 了解权限维持手段

一、CS 是什么

  • Cobalt Strike,美国 Red Team 开发的渗透测试工具。
  • 架构:服务端(teamserver)+ 客户端;多人连接同一服务端协同作战。
  • 默认端口 50050;服务端配置含密钥和指纹信息(上线前需改指纹防检测)。

二、基础流程

  1. 启动服务端:./teamserver IP 密码
  2. 客户端连接服务端(用户 test/密码)
  3. 创建监听器(HTTP/HTTPS/SMB/TCP,指定监听端口)
  4. 生成木马(Windows EXE,32/64 位)→ 投放目标 → 目标运行 → 主机上线

三、常用功能

功能 说明
生成后门 Windows EXE、Office 宏、HTA、C/PowerShell 等
文件下载 生成下载链接,诱导目标下载木马
克隆网站 克隆目标页面+键盘记录+自动下载木马
钓鱼邮件 模板+附件+代发邮箱
信息收集 浏览器/系统/IP 信息收集
凭据导出 mimikatz 读取密码
端口转发/Socks 内网渗透
会话转移 与 MSF 互转
提权 getsystem 等

四、Office 宏 / HTA 挂马

  • Office 宏:CS 生成 VBA 代码 → 粘贴到 Word/Excel 宏中;打开文档提示运行宏后上线。
  • 现代 Office 默认禁用宏,需用户手动允许。
  • HTA:HTML Application,mshta 运行,双击像软件一样打开,可直接上线。

五、CS 与 MSF 会话互转

  • CS 主机右键 → Spawn → 选择 foreign 监听器 → 会话转给 MSF。
  • MSF 端:
  • MSF 拿到的会话也可转回 CS,两工具功能互补。

六、Socks 代理内网渗透

  • CS 右键 → 中转 → Socks Server,在已上线主机上建代理隧道。
  • 隧道信息(connel)可交给 MSF,MSF 通过代理扫描/攻击内网。

Socks4 vs Socks5

  • Socks4:只支持 TCP。
  • Socks5:支持 TCP+UDP,支持身份验证、域名解析;Socks4 能做的 Socks5 都能做。

七、端口转发

  • Windows 自带 netsh(Win7+)可做端口映射转发,把内网端口映射到代理主机端口。
  • 工具主机访问代理主机某端口 = 访问内网目标端口。

八、权限维持

  • 添加服务(SC create)
  • 计划任务(定期下载运行木马)
  • 注册表/启动文件夹自启动
  • 添加隐藏用户或将 guest 加入管理员组
  • 映像劫持(屏蔽杀软,较极端)

九、插件与免杀

  • CS 支持加载插件(CNA):提权、信息收集、凭据获取、主机发现、暴力破解等。
  • 免杀:shellcode 混淆/加密生成 EXE;用世界免杀网等检测是否被杀。

十、重点速记

  • CS=客户端/服务端;监听器→木马→上线
  • 功能:后门、钓鱼、克隆网站、凭据、Socks、会话转移
  • Socks4 只 TCP,Socks5 支持 TCP+UDP
  • 权限维持:服务/计划任务/启动项/用户
  • 插件扩展功能;免杀需混淆加密
