Web 服务程序解析漏洞与文件包含漏洞

⭐ 一句话总结:解析漏洞让”图片马”被当成 PHP/ASP 执行,文件包含漏洞让服务器去加载攻击者指定的文件——两者叠加就是经典的”上传图片马 + 文件包含 = 拿下服务器”攻击链。

学习目标

  • 理解中间件解析漏洞原理
  • 掌握 IIS/Nginx/Apache 解析漏洞
  • 理解本地/远程文件包含
  • 会用伪协议读文件、执行代码
  • 掌握文件包含绕过与防御

一、解析漏洞概念

  • 中间件:客户端与资源数据之间的程序统称(LAMP 中的 Apache/PHP/MySQL 都是)。
  • Web 服务应用:Apache、Nginx、IIS、Tomcat、WebLogic、JBoss 等。
  • 解析漏洞:服务器把本不该执行的图片/未知后缀文件,当成 PHP/ASP 等脚本解析执行。
  • 目的:让上传的”图片马”里的代码运行起来。

二、IIS 解析漏洞

低版本 IIS 5.x/6.x

类型 玩法
目录解析 xx.asp/ 目录下的所有文件都按 ASP 解析
文件解析 xx.asp;.jpg 按 ASP 解析(分号截断)
文件类型解析 .cer/.asa/.cdx 等扩展名默认按 ASP 解析

高版本 IIS 7.x/8.x

  • 畸形路径解析(配置不当):x.jpg/1.php 时,若开启了 PHP CGI 映射,图片被当 PHP 执行。

三、Nginx 解析漏洞

  • 配置 cgi.fix_pathinfo=1 时:x.jpg/x.php 会把图片按 PHP 解析。
  • 经典利用:上传图片马 → 访问 shell.jpg/.php → 代码执行。
  • 修复:关闭 fix_pathinfo 或配置 if ($request_filename ~* (.*)\.php) { ... } 限制。

四、Apache 解析漏洞

  • 低版本多后缀解析:从右往左解析,不认识的后缀自动跳过,x.php.jpg 或 x.php.rar 会按 PHP 执行。
  • 修复:升级版本、配置只允许指定后缀执行、SetHandler 限制。

五、文件包含漏洞

为什么有文件包含:把公共代码(数据库连接、配置)放到单独文件,用 include 引入复用。

PHP 四个包含函数:

函数 文件不存在时
include 警告,继续执行
require 致命错误,程序中断
include_once / require_once 只包含一次

漏洞成因:用户可控的 file 参数被拼进 include,服务器去加载任意文件。

本地文件包含(LFI)

  • 可读敏感文件;配合目录穿越。

远程文件包含(RFI)

  • 前提:PHP 开启 allow_url_include=on,且 magic_quotes_gpc=off。

六、文件包含利用方式

1. 包含图片马 → RCE

上传图片马(图片头+一句话木马),再用文件包含加载:

2. 包含日志文件

  1. 访问网站时在 URL 里写入一句话木马(如 /?<?php eval($_POST[x]);?>),木马被写进 access.log。
  2. 用文件包含加载日志文件 → 代码执行。

3. PHP 伪协议

4. 00 截断

后端自动拼接 .php 时,用 %00 截断:page=shell.jpg%00(老版本 PHP 有效)。

七、绕过与防御

防御 绕过
str_replace 删 ../ 双写 ....//(只替换一次)
fnmatch 限制 file 开头 用 file:// 协议(恰好匹配)
限制扩展名 00 截断、双写扩展名

防御:

  • 白名单:文件名必须与允许列表完全相等(impossible 等级)
  • 关闭 allow_url_include
  • 过滤协议关键字和 ../
  • 用 WAF 拦截常见协议与目录穿越载荷

八、WebShell 与连接工具

  • 一句话木马(PHP):<?php @eval($_POST['jadon']);?>
  • 大马:功能完整的网页后门;小马/一句话:短小精悍。
  • 连接工具:菜刀(老)、蚁剑、冰蝎、哥斯拉。

九、重点速记

  • IIS 低版本:目录/分号/文件类型解析;Nginx:fix_pathinfo;Apache:多后缀
  • 解析漏洞目标 = 让图片马执行
  • include 警告继续,require 致命中断
  • LFI 读本地文件;RFI 需 allow_url_include=on
  • 伪协议:file://、php://filter、php://input
  • 日志包含:把马写进 access.log 再包含
  • 防御:白名单 + 关闭远程包含 + 过滤协议

参考答案 1. 让上传的图片/未知后缀文件被当成脚本解析执行。
2. 目录解析、文件解析(分号)、文件类型解析。
3. cgi.fix_pathinfo=1。
4. include 出错只警告继续,require 出错致命中断。
5. LFI 包含本机文件,RFI 包含远程服务器文件。
6. allow_url_include=on。
7. 以 base64 编码读取 PHP 源码,避免代码执行只显示内容。
8. 上传图片马后用 ?page=上传路径/马.jpg 包含执行。
9. 把一句话木马写进 URL 让服务器记入访问日志,再用文件包含加载日志文件。
10. 白名单限定可包含的文件,并关闭 allow_url_include。
