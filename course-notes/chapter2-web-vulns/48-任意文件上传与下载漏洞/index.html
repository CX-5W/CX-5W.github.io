48 · 任意文件上传与下载漏洞

任意文件上传与下载漏洞

⭐ 一句话总结:下载漏洞能让你”读”服务器任意文件,上传漏洞能让你”写”入木马——两者都是高危漏洞;核心问题都是服务端没限制路径/类型/内容,配合目录穿越、黑白名单绕过、图片马就能拿下服务器。

学习目标

  • 理解任意文件下载与目录穿越原理
  • 掌握前端/后端上传校验的绕过方式
  • 掌握黑白名单、00 截断、图片马、条件竞争
  • 会使用一句话木马连接工具

一、任意文件下载漏洞

  • 下载功能若未限制路径,可通过改 filename 参数下载任意文件。
  • 目录穿越:用 ../ 返回上级目录,下载任意位置文件。
  • 典型敏感参数:?file=, ?filename=, ?path=, ?src=, ?download=。
  • 常见目标文件:
    • Linux:/etc/passwd、/etc/shadow、/etc/nginx/nginx.conf、/root/.ssh/authorized_keys
    • Windows:C:\Windows\win.ini 等
    • 数据库配置文件:Windows 的 my.ini、Linux 的 my.cnf(可定位数据文件 → 拖库)
    • 网站源码(下载后审计)
  • 修复:过滤 ../、限制只能下载指定目录、白名单文件名、用绝对路径校验。

二、任意文件上传漏洞

上传是”写入”能力,成功上传可执行脚本(WebShell) = 控制服务器。

三、前端校验绕过

  • 特征:选完文件立即报错,没有网络请求。
  • 绕过:
    1. 修改前端 JS(删除校验代码)。
    2. 抓包改文件名后缀:选图片 → 抓包把 xxx.jpg 改成 xxx.php → 放行。

四、服务端校验与绕过

1. 后缀名黑名单

服务端禁止上传 .php/.asp/.jsp 等,绕过方式:

方式 说明
.htaccess Apache 下上传 .htaccess 让指定后缀按 PHP 解析
大小写混合 x.PHP(Windows 不区分大小写)
空格点 x.php.、x.php 、x.php. (Windows 自动去掉末尾空格和点)
NTFS 文件流 x.php::$DATA(Windows 保存后自动截断)
双写 x.pphphp(过滤只替换一次)
解析漏洞配合 分号 x.php;.jpg(IIS 解析)等

2. 后缀名白名单

只允许 jpg/png/gif,绕过:

  • MIME 类型绕过:抓包把 Content-Type 改成 image/jpeg。
  • 00 截断:
    • %00 截断(URL 中,GET 场景)
    • 0x00 截断(请求体,需在 Hex 中把空格 20 改成 00)
    • 原理:老版本 PHP(<5.3.4)处理路径时遇到 00 截断,x.php%00.jpg 保存成 x.php。

3. 内容检查

  • MIME 类型检查:改 Content-Type 绕过。
  • 文件头检查(getimagesize):
    • 在木马数据前拼上真实图片头(GIF89a 等)伪造图片。
    • 制作图片马:copy /b 图片.jpg+木马.php 马.jpg 或专用工具。
    • 上传成功但后缀是图片,需配合文件包含漏洞执行。

4. 二次渲染

  • 服务端用 imagecreatefromjpeg() 等重新生成图片,会剔除不符合图片格式的数据。
  • 绕过:反复尝试不同图片,找到”渲染后仍保留木马代码”的位置(复杂)。

五、图片马制作

  • 一句话木马示例:<?php @eval($_POST['jadon']);?>(PHP 老式);现代多用 <?php @assert($_POST['x']);?> 或加密马。
  • 连接工具:菜刀、蚁剑、冰蝎、哥斯拉;连接地址 = 上传后的文件 URL + 密码。

六、条件竞争

  • 时间竞争:上传后服务端会删除,并发狂发”上传请求 + 访问请求”,抢在删除前访问到文件 → 生成可利用文件。
  • 重命名竞争:服务端先保存再重命名,并发上传大量同名文件,个别文件没被重命名,用原文件名访问。
  • 工具:BP Intruder(攻击器)多线程发包。

七、修复建议

  • 白名单校验后缀(小写化后再校验)
  • 校验文件内容(文件头/图片重渲染)
  • 上传目录不可执行脚本(禁止解析)
  • 随机重命名文件,去掉用户可控路径
  • 限制上传大小、类型,文件单独存储域/目录

八、重点速记

  • 下载漏洞:改参数 + ../ 目录穿越 → 下载任意敏感文件
  • 上传绕过:前端改码/抓包;后端黑白名单、MIME、文件头、00 截断、图片马、条件竞争
  • 图片马需配合文件包含执行
  • 上传成功 ≠ 利用成功,还要知道文件路径并能访问执行

自测题

  2. 目录穿越用什么符号?
  3. 前端校验怎么绕过?
  4. 黑名单绕过有哪些方式?
  5. 00 截断的原理是什么?
  6. 图片马怎么制作?为什么不能直接利用?
  7. getimagesize 检查什么?怎么绕过?
  8. 时间竞争和重命名竞争的区别?
  9. 一句话木马连接需要什么?
  10. 上传漏洞修复建议有哪些?
参考答案 1. 改下载参数配合 ../ 目录穿越下载敏感文件。
2. 点点杠(../)。
3. 修改前端 JS 或抓包改文件名/类型。
4. .htaccess、大小写、空格点、NTFS 文件流、双写、解析漏洞等。
5. 老版本 PHP 处理路径时遇到 %00/0x00 就截断,后面的内容被忽略。
6. copy /b 图片+木马 生成;后缀是图片不会被解析,需配合文件包含漏洞执行。
7. 检查文件头是否为真实图片;在木马前拼图片头或制作图片马。
8. 时间竞争抢在删除前访问,重命名竞争抢在改名后仍用原名访问。
9. 文件 URL、连接密码、WebShell 管理工具。
10. 白名单后缀+内容校验+上传目录禁执行+随机重命名+限制类型大小。
