55 · 逻辑漏洞、挂马与钓鱼

逻辑漏洞、挂马与钓鱼

⭐ 一句话总结:逻辑漏洞是”程序员的思维漏洞”(改金额、绕步骤),扫描器扫不出来;挂马和钓鱼属于社会工程学——不攻击系统,而是骗人,邮件钓鱼是目前红队最常用的突破口。

学习目标

  • 理解逻辑漏洞原理与挖掘思路
  • 掌握典型逻辑漏洞案例
  • 了解挂马方式(捆绑、快捷方式、图片马、Office 宏)
  • 理解社会工程学与钓鱼
  • 掌握邮件伪造与邮件网关绕过

一、逻辑漏洞是什么

  • 功能正常,但业务逻辑处理不严谨导致的漏洞(程序员思维缺陷)。
  • 典型:支付金额可改、密码找回可越权、短信无限发送。
  • 扫描器扫不出来,只能按业务流程手工测试。
  • OWASP 分类:失效的访问控制、不安全设计等。

二、典型逻辑漏洞

类型 例子
支付漏洞 抓包把单价改为 0/负数,零元购
密码找回/修改 任意修改他人密码
权限修改 普通用户提权
注册信息泄露 响应包回显敏感注册信息
明文密码显示 页面源码/输入框 value 直接暴露密码
短信炸弹 获取验证码接口无频率限制,疯狂刷短信
无限注册 无限制创建账号
未授权访问 跳过步骤直接访问目标页面

支付漏洞修复:后台必须用数据库中的单价重新核算,不信任客户端提交的价格/数量。

三、挖掘思路

  • 完整走一遍业务流程(注册→登录→下单→支付→退款)。
  • 每一步抓包,分析可修改参数(价格、数量、ID、金额、状态)。
  • 修改参数观察响应变化。

四、不安全请求方法

  • PUT:可上传任意文件(Web 服务器默认不过滤)。
  • DELETE:可直接删除数据。
  • TRACE:返回请求/响应过程信息,泄露中间件版本等。
  • 面试必答:不安全的请求方法有 PUT、DELETE、TRACE(OPTIONS 也常算)。

五、其他常见问题

  • jQuery 低版本(<1.7)存在已知漏洞,扫描器会提示,需升级。
  • 目录浏览漏洞:配置不当导致目录可遍历。
  • SVN/Git 源码泄露:下载 wc.db/.git 可还原源码。

六、社会工程学攻击

  • 定义:不攻击系统,而是利用人的弱点(欺骗)。
  • 常见手段:钓鱼网站、钓鱼邮件、U 盘投毒、冒充身份、社工库。
  • 前提:充分的信息收集(公司、人员、邮箱、作息)。

七、挂马方式

方式 说明
EXE 捆绑 正常程序+木马捆绑,双击同时运行
快捷方式挂马 快捷方式指向远程木马,双击自动下载运行(已被补丁修复)
图片码 图片里插入一句话木马(需配合文件包含)
Office 宏 文档内恶意宏,打开即执行
Flash 挂马 已随 Flash 淘汰

⚠️ 安全意识:软件只从官网下载;别乱开邮件附件/快捷方式/压缩包。

八、邮件钓鱼

伪造发件人

  • 原理:伪造邮件服务器冒充 QQ/163 发件人。
  • 防护:SPF 等邮件安全协议——nslookup -type=TXT 163.com 看到 SPF 记录即已防伪造。
  • 现代做法:用真实邮箱服务(Mailgun、Sendinblue、QQ/163 真实账号)发钓鱼邮件。

提高成功率技巧

  • 发信频率别太高(间隔 2–5 天),大附件拆小包
  • 多变量:换 IP、换标题、换内容
  • 修改昵称伪装发件人(手机端不显示真实地址)
  • 超链接文本与实际地址不一致(文本显示官网,链接指向钓鱼站)
  • 绕过邮件网关:改标题、把内容改成英文

识别钓鱼

  • 查看发件人真实邮箱地址
  • 对比域名 Unicode 编码(防同形字符:如”币安”事件用阿拉伯字符冒充 N)
  • 不轻易点邮件链接、不下载附件

九、重点速记

  • 逻辑漏洞=业务逻辑缺陷;按流程抓包改参;扫描器扫不出
  • 典型:改价 0 元购、短信炸弹、密码找回越权、未授权访问
  • 支付必须后台重新核算
  • 不安全方法:PUT/DELETE/TRACE
  • 挂马:EXE 捆绑、快捷方式、图片码、Office 宏
  • 钓鱼=社会工程学;邮件伪造受 SPF 限制;用真实邮箱+伪装昵称
  • 识别:查真实地址、Unicode 对比、不乱点

参考答案 1. 需要理解业务流程,扫描器无法分析程序员的业务逻辑。
2. 抓包改单价/数量为 0;后台用数据库单价重新核算。
3. 验证码接口无频率限制,无限调用短信平台发送。
4. PUT、DELETE、TRACE(OPTIONS 也常算)。
5. 利用人的弱点和信任进行欺骗攻击。
6. 把木马和正常程序捆绑,双击时一起运行。
7. SPF 等邮件安全协议。
8. 改标题、改内容(如英文)、控制频率和多变量。
9. 查发件人真实地址、对比域名编码、不轻易点链接。
10. 使用与字母 N 相似的 Unicode 同形字符伪造域名。
