MySQL 进阶操作

⭐ 一句话总结:SQL 四大关键字 insert/select/update/delete 是操作核心;查询(where/order/limit/union)更是SQL 注入的必修课;索引让百万行数据秒查。

学习目标

  • 掌握建表、数据类型、约束
  • 熟练行数据的增删改查与条件查询
  • 会用内置函数、索引、union 联合查询
  • 知道存储引擎和备份恢复

一、数据类型

类型 用途
int / bigint 整数(4/8 字节)
float 小数(如价格 999.99)
char(定长) / varchar(变长) 字符串(姓名、密码;varchar 省空间但稍慢)
text 长文本(描述、小说,longtext 可存 4G)
enum 枚举多选一(如 男士/女士表)
date 日期(存 Unix 时间戳)
布尔 真假

二、创建表与约束

  • 常用约束:NOT NULL(必填)、DEFAULT(默认值)、UNIQUE(唯一)、PRIMARY KEY(主键)。
  • 字符集:默认 latin 不支持中文,建库/建表指定 utf8mb4 才支持全部中文。
  • 查看表结构:desc 表名。

三、行数据增删改查(重点)

⭐ 重点:delete/update 一定要带 where 条件,否则全表数据被清空/改掉!

四、查询进阶(注入基础)

  • 字符串值必须加引号(单引号)——SQL 注入的引号闭合就是从这里来的。
  • like + 百分号通配符;order by 排序;limit 限制条数(索引从 0 开始)。

五、索引(加速查询)

  • 索引 = 数据的”目录”,百万行数据没索引查 0.3 秒,有索引秒查。
  • where 条件用了带索引的列才生效。
  • 主键特点:不能空、不能重复、可自增(auto_increment)。

六、union 联合查询(注入关键)

  • 作用:把多个 select 结果合并成一张表;前后列数必须一致。
  • 注入常用:union select 1,2,3、union select database(),user(),version() 把数据库名/用户/版本显示出来。

七、存储引擎、备份与恢复

  • InnoDB(默认):读写均衡,2 个文件(数据 .ibd + 结构 .frm)。
  • MyISAM:读快写慢,3 个文件(数据/索引/结构)。
  • 备份:mysqldump -u root -p 库名 > 备份.sql(全量备份,里面全是 SQL 语句)。
  • 恢复:mysql -u root -p 库名 < 备份.sql。

八、重点速记

  • 增删改查:insert / select / update / delete;删除修改必须带 where
  • 条件:where、and/or、like、between、order by、limit
  • 字符串要加引号;count/sum/concat 常用
  • 索引加速:主键/唯一/普通;union 列数必须一致
  • 字符集 utf8mb4;InnoDB 默认;mysqldump 备份

自测题

  1. 插入、查询、修改、删除的关键字是什么?
  2. NOT NULL、DEFAULT、UNIQUE 分别控制什么?
  3. 查询”山东或山西、人口大于100万”怎么写?
  4. like ‘山%’ 表示什么?
  5. order by 和 limit 的作用?
  6. 索引为什么能加速?主键有什么特点?
  7. union 查询有什么要求?注入里常查哪三个函数?
  8. 数据库怎么备份和恢复?
参考答案 1. insert、select、update、delete。
2. 不能为空、默认值、不能重复。
3. `where (district='山东' or district='山西') and population>1000000`。
4. 以"山"开头的模糊匹配。
5. 排序和限制返回条数。
6. 像目录一样定位数据;主键不能空、不能重复、可自增。
7. 前后列数必须一致;database()、user()、version()。
8. mysqldump 导出成 .sql,再用 mysql < 文件导入。
