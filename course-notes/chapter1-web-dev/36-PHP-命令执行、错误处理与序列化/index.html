36 · PHP 命令执行、错误处理与序列化

PHP 命令执行与序列化

⭐ 一句话总结:PHP 能直接执行系统命令(system/exec 等),也支持类、魔术方法和序列化;两者叠加就是经典”反序列化漏洞”的攻击链,是后续渗透学习的核心原理。

学习目标

  • 知道 PHP 执行系统命令的函数和”回显”概念
  • 掌握错误级别、display_errors、日志配置
  • 会用 preg_match / preg_replace 做正则匹配
  • 理解 class、对象、魔术方法
  • 看懂 serialize / unserialize 和反序列化漏洞原理

一、命令执行函数

  • 命令在服务端执行,不是在浏览器;输出叫”回显”。
  • 可以创建文件夹(md/mkdir)、写文件(echo xxx > a.txt)等。

⭐ 重点:如果用户输入能拼进命令参数,就形成命令执行漏洞,攻击者可在服务器上执行任意指令。WebShell 木马就经常内置命令执行功能。

二、错误处理

错误级别:

级别 严重程度 是否中断
error 严重错误 中断执行
warning 警告 继续执行
notice 提示小问题 继续执行
parse 解析错误(语法/组件) 编译失败
  • 生产环境应关闭错误显示:display_errors = Off(php.ini)或代码开头 ini_set('display_errors', 0)。
  • 代码里改配置只对当前文件生效,不用重启;改 php.ini 必须重启服务。
  • 定制错误级别:error_reporting(E_ALL & ~E_NOTICE);error_reporting(0) 全关。
  • 日志:log_errors = On 开启记录;log_errors_max_len 单条最大长度(默认 1024B);error_log 指定日志位置。
  • Windows 默认记到”事件查看器-应用程序日志”;Linux 默认 /var/log/syslog。
  • error_log("内容") 可手动写日志。
  • phpinfo.php 不能留在网站里:会暴露版本、路径、配置等全部信息,等于”裸奔”。
  • 常见服务日志路径:Nginx /usr/local/nginx/logs/access.log|error.log;Apache Linux /etc/httpd/logs/error_log(面试常考)。

三、正则表达式

  • 正则写法固定:/表达式/。
  • 用于校验手机号、邮箱、身份证等格式;网上可在线生成对应语言代码。

  • 类名一般首字母大写;类用 class 定义,实例化用 new。
  • 类内用 $this->属性名 访问自己的属性。

五、序列化与反序列化

  • 序列化字符串示例:a:3:{i:0;s:1:"a";i:1;i:33;...} —— a 表示数组,数字表示元素个数/长度。
  • 对象序列化:O:5:"Fruit":2:{...} —— O 表示对象,5 是类名长度,2 是属性个数;方法不会被序列化,反序列化后对象仍可调用方法。
  • 作用:跨语言/跨项目传数据(Java 有对应机制)。

六、反序列化漏洞原理(重点)

  1. 攻击者构造恶意序列化字符串,里面包含会执行恶意动作的类(如 __destruct 里写 system(“net user …”))。
  2. 目标程序对不可信数据执行 unserialize()。
  3. 对象用完销毁时 __destruct 自动触发,恶意命令在服务器上执行。
  • 危害:创建用户、开启远程桌面、控制整台服务器。
  • 常见案例:Java WebLogic、Fastjson、Shiro 1.2.4、PHP 反序列化漏洞。

⭐ 重点:反序列化 = 魔术方法 + 命令执行 + 用户可控数据;看到对用户输入 unserialize 要高度警惕。

七、重点速记

  • system 完整回显,exec 回显不全;命令在服务端执行
  • 错误级别 error/warning/notice;生产环境 display_errors=Off
  • ini_set 只对当前文件生效;error_reporting 定制显示/记录
  • preg_match 匹配一次、preg_match_all 全匹配、preg_replace 替换
  • class/new/属性/方法/$this;__construct/__destruct 自动触发
  • serialize/unserialize;反序列化漏洞 = 魔术方法 + 命令执行

  1. 执行系统命令的 PHP 函数有哪些?
  2. system 和 exec 回显有什么区别?
  3. 生产环境为什么关闭 display_errors?
  4. error、warning、notice 有什么区别?
  5. ini_set 和改 php.ini 有什么区别?
  6. 类里的变量和函数分别叫什么?
  7. __construct 和 __destruct 什么时候触发?
  8. 反序列化漏洞的成因是什么?
参考答案 1. system、exec、passthru、shell_exec。
2. system 完整回显,exec 回显不完整。
3. 防止暴露代码路径等敏感信息,避免被攻击者利用。
4. error 中断程序,warning 继续执行,notice 只提示小问题。
5. ini_set 只对当前文件生效且不用重启,改 php.ini 需重启服务。
6. 属性和方法。
7. new 创建对象时触发 __construct,对象销毁时触发 __destruct。
8. 对用户可控数据反序列化,对象销毁时魔术方法自动执行恶意命令。
