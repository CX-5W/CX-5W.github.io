33 · PHP 后端基础

PHP 后端基础

⭐ 一句话总结:PHP 的作用是”动态生成 HTML”——接收前端数据、加工、查数据库、把结果塞进页面;看懂 PHP 是理解漏洞原理的前提。

学习目标

  • 理解前后端交互流程(PHP 怎么接收数据、输出页面)
  • 掌握变量、常量、数据类型
  • 会用运算符和 if 判断
  • 学会防乱码、调试基础

一、PHP 是什么

  • PHP(超文本预处理器):后端语言,把 HTML 动态加工后返回浏览器;浏览器不认识 PHP,必须由 Apache/Nginx 交给 PHP-FPM 解析。
  • 历史:1995 年诞生;主流版本 PHP 5.x 和 7.x(稳定、长期支持)。
  • 为什么学它:大量开源项目和漏洞复现基于 PHP,安全人员要看得懂。
  • 开发环境:PHPStudy(集成 Apache/MySQL/PHP),站点目录 www。

二、前后端交互流程

  • PHP 文件里可以直接写 HTML 标签;PHP 代码用 <?php … ?> 包裹,语句以分号结尾。
  • 乱码解决:header("Content-Type: text/html; charset=utf-8");

三、变量与常量

  • 变量以 $ 开头;字母或下划线开头,后面可跟字母/数字/下划线;不能用中文和特殊符号。
  • 常量一般大写,用 define 或 const 定义,const 不能用在 if 里。

四、数据类型

类型 说明
bool true/false,0=假,非0=真
int / float 整数 / 小数
string 字符串(引号包裹)
array 数组(容器,可放多种数据)
object 对象(类实例化)
resource 资源(文件等)
null 空
  • 数组取值:$s[0](索引从 0 开始);查看类型:gettype()、var_dump()(更详细)。
  • echo 只能打印字符串/数字,打印数组会报错。

五、字符串与引号

  • 单引号不解析变量、双引号解析变量;拼接用 .。

六、运算符

类别 符号
算术 + - * / %(取余)、.(拼接)、-(取负)
赋值 =、+=、-=、*=、/=、.=
比较 ==(弱等于)、===(强等于,比较类型)、!=、>、<
逻辑 and/&&、or/||、xor(异或)、!(取反)
自增自减 $a++(先使用后+1)、++$a(先+1再使用)
三元 条件 ? 值1 : 值2

⭐ 重点:== 不比较类型(“10”==10 为真),=== 比较类型;乘除优先于加减,括号提升优先级。

七、流程控制 if

  • 条件成立执行 if 块,否则依次判断 elseif,最后走 else。
  • 逻辑运算符常用于登录判断:if ($u=='jadon' && $p=='123')。

八、重点速记

  • PHP 动态生成 HTML;PHP-FPM 解析;<?php ?> 写代码
  • 接收数据 $_GET['键'] / $_POST['键'];输出 echo
  • 变量 $ 开头;常量 define/const;引号:单引号不解析、双引号解析
  • 数据类型:bool/int/float/string/array/null
  • 运算符:== 弱等于、=== 强等于;&& / || / !;. 拼接
  • if/elseif/else 判断

自测题

  1. 浏览器为什么不能直接识别 PHP?
  2. 接收 GET 提交的用户名怎么写?
  3. 变量和常量的区别?
  4. 单引号和双引号的区别?
  5. == 和 === 的区别?
  6. $a++ 和 ++$a 的区别?
  7. PHP 中文乱码怎么解决?
参考答案 1. PHP 是后端语言,必须由 PHP-FPM 解析成 HTML 后返回。
2. `$_GET['username']`。
3. 变量可重新赋值,常量定义后不可改。
4. 双引号解析变量,单引号原样输出。
5. == 不比较类型,=== 比较类型和值。
6. 先使用后自增 / 先自增再使用。
7. header("Content-Type: text/html; charset=utf-8")。
