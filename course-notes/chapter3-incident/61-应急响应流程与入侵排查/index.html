61 · 应急响应流程与入侵排查

应急响应流程与入侵排查

⭐ 一句话总结:应急响应 = 检测 → 抑制 → 根除 → 恢复 → 跟进;排查从”异常连接”入手,按”账号→日志→进程→服务→启动项→计划任务→文件”逐项检查,把木马和后门清干净。

学习目标

  • 掌握应急响应五阶段
  • 掌握 Windows 入侵排查流程
  • 会用日志、进程、服务、启动项排查
  • 会使用 ARK/WebShell 查杀工具
  • 能讲清楚一次完整应急过程

一、应急响应五阶段

  1. 检测:发现异常(CPU 高、异常连接、网页被挂马)。
  2. 抑制:断网/断电,防止病毒扩散到内网其他主机。
  3. 根除:删除病毒文件、进程、后门。
  4. 恢复:修复文件、恢复服务。
  5. 跟进:持续监控,确认无复发。

二、常见应急事件

  • 网页挂马、主页篡改
  • WebShell 后门
  • 木马远控(灰鸽子、PCShare 等)
  • 勒索病毒(WannaCry,比特币支付)
  • 挖矿病毒、DDoS

三、Windows 入侵排查流程(重点)

1. 系统账号

  • 本地用户和组:查看可疑账号、Guest 是否被启用、用户组是否被改。
  • 隐藏账号:注册表 HKLM\SAM\SAM\Domains\Account\Users\Names 对比。
  • 克隆账号:地盾等工具检测。
  • 弱口令:与运维核实,或用扫描器检测。

2. 远程桌面

  • 检查远程桌面(3389)是否被开启;入侵者常开 RDP 便于长期控制。

3. 日志分析

  • 事件查看器 → Windows 日志 → 安全日志。
  • 事件 ID:4624(登录成功)、4625(登录失败)、4672(特殊权限登录)、4720(创建用户)等。
  • 大日志可”将所有事件另存为”后分析;用 Log Parser 分类。

4. 异常端口与进程

  • 外部公网 IP 与本地建立连接 = 可疑(排除 127.0.0.1)。
  • svchost.exe 是系统主进程,不要乱杀;要查它加载的 DLL 模块签名。

5. 服务

  • 可疑服务名(随机乱名、无签名):services.msc 查看,清理注册表对应项。

6. 启动项与计划任务

  • 启动文件夹、注册表 Run 键、组策略启动项。
  • 计划任务(schtasks)。
  • 恶意软件常写 .bat/.vbs/.dll 实现开机自启。

7. 系统信息与补丁

  • 打补丁前先在测试环境验证,避免影响业务。

8. 可疑文件

  • 查看近期修改/创建的文件和目录;注意攻击者可能伪造时间。

四、常用工具

工具 用途
地盾 WebShell 查杀、克隆/隐藏账号检测
河马 WebShell 查杀(命令行)
火绒剑 进程/文件/启动项分析
PCHunter(ARK) 反内核工具,查看隐藏文件/进程/模块签名
在线沙箱/杀毒网 VirusTotal、世界杀毒网,检测文件是否恶意
Procmon/文件监控 动态分析病毒行为

五、木马与病毒的区别

  • 木马:以控制为主(远控、当肉鸡)。
  • 病毒:以破坏为主(删改文件、勒索)。

六、实战案例(灰鸽子/PCShare)

典型处理流程:

  1. 发现异常对外连接(国外/非内部 IP)。
  2. netstat -ano 找 PID → tasklist 定位进程。
  3. 发现是 svchost 主进程 → 用 ARK 工具查看其加载模块,找到无签名 DLL。
  4. 删除 DLL 文件 → 结束进程 → 清理可疑服务和注册表。
  5. 检查启动项、计划任务、异常账号、远程桌面,确认无后门残留。

⭐ 面试话术:按”发现异常连接→定位进程→找到无签名模块→删文件→杀进程→清服务/注册表→复查启动项/计划任务/账号”完整讲一遍。

七、重点速记

  • 五阶段:检测→抑制→根除→恢复→跟进
  • 排查顺序:账号→日志→进程→服务→启动项→计划任务→文件→补丁
  • netstat -ano 看异常连接;PID→进程→模块签名
  • svchost 别乱杀,查挂载 DLL
  • 工具:地盾、河马、火绒剑、PCHunter、在线沙箱
  • 木马控制、病毒破坏
