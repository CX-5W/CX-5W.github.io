Windows 病毒查杀与 Linux 入侵排查

⭐ 一句话总结:Windows 查病毒看”进程→文件→注册表→启动项”,小心映像劫持;Linux 排查靠”账号→历史命令→端口进程→定时任务→日志”,重点记住 /etc/passwd、secure 日志、crontab、rkhunter。

学习目标

  • 掌握 Windows 病毒手动查杀流程
  • 理解映像劫持技术
  • 掌握 Linux 入侵排查关键命令
  • 能讲挖矿病毒、暴力破解应急案例

一、Windows 病毒查杀(维金病毒案例)

感染特征

  • 磁盘右键菜单多了”Auto”打开项
  • 出现 autorun.inf(U 盘传播)
  • 进程 DLLHOST.EXE 等可疑进程

查杀流程

  1. 分析进程(大写/异常进程名)。
  2. 通过 PID 找到程序文件。
  3. 删除病毒程序文件 → 结束进程。
  4. 清理注册表启动项、删除 autorun.inf。
  5. 重启验证是否复发。

提示:病毒文件可能被占用删不掉,可进安全模式或使用 ARK 工具。

二、映像劫持(IFEO)

  • 位置:HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options
  • 原理:把杀毒软件/注册表等程序路径改成不存在的程序,导致无法启动。
  • 排查:该注册表项下出现大量杀软名称且路径异常 = 被劫持。
  • 突破:改名运行、删除恶意注册表项、用 PCHunter 等 ARK 工具删除。

三、Linux 入侵排查(重点命令)

1. 账号安全

2. 历史命令

  • 修改 /etc/profile 增大记录条数并带时间/用户/IP:

3. 端口与进程

  • 系统指令文件(ps/ls)可能被替换:用同版本系统文件替换。

4. 开机自启与计划任务

5. 日志

6. 查杀工具

  • rkhunter / chkrootkit:rootkit/后门检测
  • ClamAV:开源杀毒
  • 河马:WebShell 查杀
  • RPM -Va:校验安装包文件是否被篡改

四、真实案例

挖矿病毒

  1. top 发现 CPU 100% 的可疑进程。
  2. 查看定时任务,发现可疑脚本(如 root/pwn.sh)。
  3. 分析脚本:下载木马、加锁、防二次下载、清理日志等。
  4. 删除脚本和下载文件、结束进程、清理计划任务。

FTP/SSH 暴力破解

  • 现象:服务器变慢,重启后反复。
  • 排查:安全日志大量 4625 登录失败;Log Parser 提取分析;netstat 看连接;抓包定位攻击 IP。
  • 处置:关闭/限制 FTP 外网端口,改强密码,加登录限制。

五、重点速记

  • Windows:进程→文件→注册表→启动项→autorun.inf→重启验证
  • 映像劫持:IFEO 注册表;改名/删项/ARK 突破
  • Linux:passwd/who/history/netstat/ps/crontab/secure
  • 定时任务藏挖矿;安全日志查爆破
  • 工具:rkhunter、chkrootkit、ClamAV、河马

参考答案 1. 分析进程→定位程序文件→删文件→杀进程→清注册表/启动项→重启验证。
2. 磁盘/优盘自动运行文件,用于传播病毒。
3. 注册表IFEO把程序路径改错,导致程序无法启动。
4. cat /etc/passwd。
5. awk -F: '$3==0{print $1}' /etc/passwd。
6. ~/.bash_history;修改/etc/profile增加HISTSIZE和HISTTIMEFORMAT。
7. crontab -l、/var/spool/cron、/etc/crontab。
8. /var/log/secure。
9. 定时任务+下载脚本+临时目录文件。
10. 关外网FTP端口、查安全日志4625、改强密码、限制登录。
