数字取证 Forensics

🔍 数字取证 Forensics

取证方向两大主线：流量分析（抓包文件）和文件取证（磁盘/内存/日志）。CTF 里最常见的是 PCAP 流量分析和文件隐写。

📡 流量分析（PCAP）

工具链

工具 用途
Wireshark 图形化看包，过滤 + 追踪流
tshark 命令行版，适合批量提取
NetworkMiner 自动提取文件/图片
在线分析 大型 pcap 快速预览

Wireshark 常用过滤

常见套路

  1. 看协议统计：Statistics → Protocol Hierarchy，找异常协议
  2. 追踪 HTTP 流：登录表单、上传文件、POST 参数里常藏 flag
  3. 提取传输文件：File → Export Objects → HTTP/SMB，导出可疑文件
  4. DNS 隧道：子域名里拼字母 → 按序拼接
  5. USB 键盘流量：USB HID 数据还原按键
  6. 蓝牙/无线包：配对过程提取密钥

📁 文件取证

场景 手法 工具
磁盘镜像 文件恢复 / 删除文件找回 Autopsy / foremost
内存镜像 进程 / 命令行 / 文件提取 volatility3
日志分析 登录记录 / 攻击痕迹 grep / splunk
Office 文档 宏病毒 / 隐藏内容 olevba / 7z 解包
PDF 恶意样本 JS 提取分析 pdf-parser
