面试高频问答 100 题

从 45 篇笔记的「面试问答」汇总的高频题库，覆盖协议 / 信息收集 / Web 漏洞 / 工具 / 内网域 / 应急 / 开发。面试前过一遍，心里有底。

★重点 答案均为要点版，答题时记得”先结论、再展开、带例子”。

一、基础与网络协议（12）

  1. HTTP 请求包格式？ A：请求行、请求头、空行、请求体；GET 无体、POST 有体。
  2. GET 和 POST 区别？ A：数据位置（URL vs 请求体）、长度、类型、幂等性、场景（查 vs 增改）。
  3. HTTP 状态码常考？ A：200 成功、301/302 重定向、304 缓存、403 禁止、404 不存在、500/502/504 服务端问题。
  4. 304 原理？ A：带缓存修改时间给服务端对比，无变化返回 304 用本地缓存。
  5. HTTPS 握手流程？ A：客户端发握手 → 服务端回证书 → 客户端验签+摘要比对 → 公钥传预密钥 → 双方合成对称密钥 → 加密通信。
  6. 为什么 HTTPS 用三种算法？ A：哈希验完整性、非对称做认证和密钥协商、对称加密传数据。
  7. 什么是同源？ A：协议+域名+端口全同；同源策略拦”读取”不拦”发送”。
  8. 跨域方式？ A：CORS 响应头、五大跨域标签、JSONP 回调。
  9. Cookie 和 Session？ A：HTTP 无状态，服务端 Session 存状态，Set-Cookie 下发会话 ID，请求自动携带。
  10. TCP 三次握手/四次挥手？ A：SYN→SYN+ACK→ACK；FIN→ACK→FIN→ACK。
  11. SYN 洪水原理？ A：伪造海量 SYN 占满半连接队列，正常用户无法建连。
  12. MD5 密码怎么破解？ A：不可逆但可撞库/彩虹表；防御用加盐+慢哈希（bcrypt/argon2）。

二、信息收集与扫描（12）

  1. 为什么信息收集是核心？ A：成败约 80% 取决于它；版本匹配漏洞、子域找薄弱点、CDN 绕过找源站。
  2. 信息收集收集什么？ A：域名/子域、真实 IP、端口服务、指纹版本、目录文件、旁站 C 段、测绘。
  3. 怎么判断有 CDN？ A：多地 Ping，多地区多 IP=CDN；单 IP=真实源站。
  4. CDN 绕过方法？ A：子域名排查（最稳）、历史 DNS、邮件头、国外服务器 Ping。
  5. Nmap 常用参数？ A：-sn 主机发现、-sS SYN、-sT 全连接、-sV 版本、-O 系统、-A 综合。
  6. -sS 和 -sT 区别？ A：SYN 半连接隐蔽快需 root；全连接完整握手无权限但易被记录。
  7. ping 不通说明主机不在？ A：不一定，Windows 防火墙默认拦 ICMP，用 -sn 多协议探测。
  8. 指纹识别怎么手工判断？ A：响应头 Server/X-Powered-By + 源码关键词（wp-content、thinkphp 等）。
  9. Git 泄露怎么检测利用？ A：访问 /.git/HEAD 确认，GitHack 还原源码，git log 挖历史敏感信息。
  10. 目录扫描原理？ A：路径字典批量拼接发包，按状态码判断（200/301/403=存在）。
  11. Google Hack 常用语法？ A：site/inurl/intitle/intext/filetype/- 组合。
  12. 旁站和 C 段？ A：旁站=同 IP 多站点；C 段=同网段主机；主站打不动打旁站。

三、Web 漏洞（30）

  1. SQL 注入原理？ A：用户输入未过滤直接拼接 SQL 执行，本质是信任失控。
  2. 怎么判断数字型/字符型？ A：数字型直接拼 and 1=1；字符型加引号报错、需闭合。
  3. 注入分类？ A：按类型（数字/字符/搜索/堆叠）、按位置（GET/POST/Cookie）、按回显（联合/报错/布尔/时间）。
  4. 联合查询注意？ A：order by 测列数、列数一致、回显位替换、Access 末尾需真实表名。
  5. 报错注入原理？ A：updatexml/extractvalue 非法 XPath 报错带出数据，单次 32 字符。
  6. 写 Shell 条件？ A：secure_file_priv 开放 + 绝对路径 + 写权限，最好 root。
  7. SQLMap 常用？ A：--dbs --tables --columns --dump；登录态 -r；WAF --tamper。
  8. 预编译为什么能防注入？ A：SQL 结构固定，输入只当值绑定；局限是动态表名/排序等。
  9. XSS 三类区别？ A：存储型入库持久高危；反射型 URL 一次性；DOM 型前端动态渲染。
  10. XSS 怎么验证？ A：<script>alert(1)</script> 或 <img src=x onerror=alert(1)> 弹窗。
  11. 属性内输出怎么打 XSS？ A：引号闭合+事件注入：' onclick=alert(1) >。
  12. XSS 危害？ A：窃取 Cookie 冒充登录、键盘记录、钓鱼；管理员中招=后台沦陷。
  13. XSS 防御？ A：输入过滤+输出转义双端，CSP 兜底。
  14. 文件上传怎么绕过？ A：前端删 JS/改包；MIME 改 Content-Type；文件头做图片马；后缀大小写双写截断。
  15. 图片马能直接用吗？ A：不能，需解析漏洞/文件包含配合执行。
  16. 解析漏洞有哪些？ A：IIS6 分号截断/目录解析；Apache 多后缀回溯；Nginx fix_pathinfo。
  17. 文件包含怎么产生？ A：include 路径用户可控无白名单；包含函数不校验后缀只解析内容。
  18. LFI 和 RFI？ A：LFI 本地文件无配置要求；RFI 远程 URL 需 allow_url_include 开启。
  19. 命令执行危险函数？ A：PHP system/exec/shell_exec/反引号；eval/assert。
  20. 命令连接符？ A：; 无条件、&& 成功才执行、|| 失败才执行、| 管道。
  21. 反序列化漏洞原理？ A：不可信序列化串直接 unserialize，触发魔术方法执行代码。
  22. 反序列化常见组件？ A：WebLogic、Shiro、Fastjson、Apache Commons。
  23. 什么是 SSRF？ A：服务端代替攻击者发请求，可探测内网、读文件。
  24. SSRF 绕过？ A：进制转换、IP 简写、@ 解析、重定向。
  25. 什么是 XXE？ A：XML 外部实体注入，读文件/内网请求，无回显用报错或外带。
  26. 逻辑漏洞为什么扫不出来？ A：无特征码，藏在业务逻辑里，只能手工结合业务测。
  27. 常见逻辑漏洞？ A：支付改价、状态参数篡改、密码找回绕过、短信轰炸、越权。
  28. 越权分类？ A：未授权访问、水平越权（同级换 ID）、垂直越权（低权限高操作）。
  29. 怎么测垂直越权？ A：两个账号，管理员操作抓包，换普通用户身份信息放包。
  30. 暴力破解验证码绕过？ A：前端删 JS/删字段；后端吃时效（60 秒内复用）或纯数字爆破。

四、工具与对抗（10）

  1. AWVS 定位？ A：Web 漏洞扫描器，配登录态扫后台，报告分级，高危必须手工验证。
  2. Xray 特点？ A：单文件免装、少发包高精准、POC 可定制、反连平台，和 Burp 联动。
  3. Xray 和 AWVS 分工？ A：AWVS 全量初筛，Xray 精准复核/免打扰扫描。
  4. Nessus 做什么？ A：系统漏洞扫描，8834 网页管理，免费版限 16 IP。
  5. CS 是什么？ A：红队平台，客户端-服务端，Beacon 控主机，集成提权/凭据/代理/钓鱼。
  6. CS 和 MSF 配合？ A：会话互转，能力互补。
  7. 有状态/无状态木马？ A：有状态自动持久化易被杀；无状态只起进程，需手动 sc create 持久化。
  8. WAF 怎么识别？ A：发攻击载荷看响应/wafw00f；规则库匹配不到=放行。
  9. WAF 绕过思路？ A：编码、大小写、注释、等价替换、分块传输、换请求位置。
  10. 免杀怎么做？ A：基于语言特性变形（变量/拼接/编码/自定义函数）+加壳；写完用杀软测、能连才算。

五、内网与域（15）

  1. 内网渗透思路？ A：先完全控制外网主机 → 信息收集 → 代理/隧道打通 → 横向扩大。
  2. 不出网怎么办？ A：Socks 代理（EW/reGeorg）或隧道（ICMP/DNS）转出。
  3. 代理和隧道区别？ A：代理转发不换协议；隧道把数据加工成其他协议绕过过滤。
  4. FRP 干什么？ A：NAT 穿透，公网服务器做映射，目标经公网回连。
  5. 内网信息收集什么？ A：系统/补丁、用户组、杀软、防火墙、端口服务、域信息。
  6. 端口转发工具？ A：NC、LCX（转出什么端口用对应工具接）。
  7. 横向渗透手法？ A：口令复用、PTH、永恒之蓝、弱口令爆破、Web 漏洞复用。
  8. 工作组 vs 域？ A：工作组只分组无统一管理认证；域靠 DC 统一管理和认证。
  9. Kerberos 认证链？ A：AS 验身份→TGT→TGS 换票→ST→服务放行。
  10. 黄金票据？ A：伪造 TGT，需要 krbtgt 哈希+SID，可申请任意服务票，通常做权限维持。
  11. 白银票据？ A：伪造 ST，需要目标服务账号哈希+SID，只能访问单个服务。
  12. PTH 和 PTT？ A：PTH 用哈希直接认证；PTT 导入票据冒充身份。
  13. 定位域控？ A：nltest / net group “domain controllers” / whoami /all；拿下域控=控制全域。
  14. Kerberoasting？ A：申请服务票据离线爆破服务账号密码。
  15. 提权思路？ A：先信息收集（版本/补丁/权限），再匹配漏洞 EXP；Windows 补丁、Linux SUID/内核、数据库 SA。

六、应急与运营（13）

  1. 应急响应六阶段？ A：准备→启动→检测→抑制→根除→恢复→跟进。
  2. 挖矿病毒怎么处理？ A：断网→查异常连接/进程→删文件→清计划任务启动项→修漏洞→复查。
  3. 为什么先杀进程再删文件？ A：运行中的程序会自我恢复/保护文件。
  4. 映像劫持？ A：注册表把杀软路径改错导致打不开；改名绕过/SREng 清理。
  5. Linux 排查要点？ A：passwd 异常账号、authorized_keys 后门、计划任务、日志。
  6. Web 应急流程？ A：隔离→扫 WebShell→日志定位→清理→修复→复测。
  7. 护网蓝队分组？ A：监测→研判→处置(封IP)→溯源→反制。
  8. 怎么研判攻击？ A：数据包特征+攻击次数+历史行为，结合资产判断真假与成败。
  9. 等保流程？ A：定级备案→差距评估→建设整改→等级测评。
  10. 等保 2.0 十方面？ A：物理、通信、区域边界、计算环境、管理中心+管理五方面。
  11. 安全加固做什么？ A：口令复杂度/锁定、账号清理、日志开启、补丁、关端口。
  12. 常见安全设备？ A：防火墙、WAF、IDS/IPS、态势感知、VPN、抗DDoS、审计。
  13. 渗透测试报告要素？ A：概述、资产、漏洞清单分级、复现截图、修复建议、总结。

七、安全开发（8）

  1. POC 和 EXP 区别？ A：POC 验证漏洞存在；EXP 利用漏洞拿权限；Payload 是恶意载荷。
  2. 为什么安全要学 Python？ A：大量安全工具/POC 是 Python 写的，能看懂能改能自写。
  3. requests 和 socket？ A：requests 应用层 HTTP 封装；socket 底层灵活（端口扫描/自定义协议）。
  4. 怎么模拟登录态爬数据？ A：浏览器复制 Cookie/UA 放进 headers。
  5. 端口扫描为什么用 connect_ex？ A：不抛异常、返回 0=开放、速度快。
  6. 爆破脚本怎么提速？ A：queue 队列+threading 多线程并发取任务，避免重复。
  7. 代码审计从哪入手？ A：搜危险函数（system/eval/include/unserialize）→追数据来源→查过滤。
  8. 怎么保证脚本稳定？ A：try/except 容错、timeout、控制线程、打印进度。
