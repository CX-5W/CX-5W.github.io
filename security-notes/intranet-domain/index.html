内网渗透与域渗透速查

内网渗透三大问：主机不出网怎么办？怎么横向？域怎么打？速查表一条线讲清。

一、三种出网场景三种打法

★重点 面试高频

场景 技术 工具
能上网但连不上 NAT 穿透 FRP / ngrok / NPS
纯内网不出网 Socks 代理 EW / reGeorg + Proxifier
数据被防火墙拦 隧道换协议 ICMP(pingtunnel) / DNS(CS)

代理 vs 隧道：代理转发数据不换协议；隧道把数据加工成其他协议绕过过滤。

四、横向渗透

  • 口令复用（同一密码多台机器）。
  • PTH 哈希传递：psexec / Impacket（知道哈希即可认证）。
  • 永恒之蓝 MS17-010（445，老系统）。
  • 弱口令爆破 SMB/3389/SSH/数据库。
  • 代理打通后，内网渗透 = 公网渗透。

五、提权速查

系统 手法
Windows 补丁漏洞 EXP（systeminfo 查补丁）、服务缺陷、令牌窃取
Linux SUID（find / -perm -4000）、内核漏洞、sudo 配置不当
数据库 MSSQL SA + xp_cmdshell、MySQL UDF/写文件

六、域渗透

面试高频 工作组 vs 域：工作组无统一管理/统一认证；域通过 DC（AD）统一管理。

Kerberos 认证链：AS 验身份 → TGT(黄金票据) → TGS 换票 → ST(白银票据) → 服务放行。

攻击 前提 效果
PTH 密码哈希 直接认证登录
PTT 票据文件 导入票据冒充身份
黄金票据 krbtgt 哈希+SID 伪造 TGT，通吃全域（权限维持）
白银票据 目标服务账号哈希+SID 伪造 ST，访问单个服务
Kerberoasting 域内普通用户 拿服务票据离线爆破

工具：Mimikatz（kerberos::golden / kerberos::ptt）、Impacket、BloodHound、CS + Landon 插件。

★重点 记忆：定位域控 → 抓凭据 → PTH/PTT 横向 → 拿 krbtgt 伪造黄金票据 → 控制全域。
