★重点 面试高频

四、常见事件处置

事件 特征 处置
挖矿病毒 CPU 飙高、连接矿池 断网→定位进程文件→删除→清计划任务→修漏洞

五、Web 应急

攻击入口三来源：系统漏洞（135/445）、Web 漏洞（注入/上传拿 Shell）、后台弱口令。

排查流程：异常连接 → 进程 → Web 目录（D 盾扫 WebShell）→ 访问日志定位攻击路径 → 清理修复 → 复查。

六、护网与安全设备

蓝队分组：监测 → 研判 → 处置(封IP) → 溯源 → 反制。

设备：防火墙(边界)、WAF(应用)、IDS/IPS、态势感知(天眼)、防病毒网关、VPN、抗DDoS。

研判要点：数据包特征（select union、cat /etc/passwd）+ 攻击次数 + 50x 状态码（被拦截）。

七、等保速记

面试高频 流程：定级备案 → 差距评估 → 建设整改 → 等级测评。

2.0 十方面：物理、通信网络、区域边界、计算环境、管理中心 + 管理五方面（制度/机构/人员/建设/运维）。

加固核心：身份鉴别（口令 8 位+锁定）、访问控制、安全审计（日志）、补丁、关端口。
