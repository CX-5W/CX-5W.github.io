安全工具库

🧰 安全工具库

个人常用的安全测试工具整理：按用途分类，附官方下载地址与快速上手命令。所有工具仅用于授权测试与自有靶场。

🕸 抓包与 Web 测试

Burp Suite

Web 安全测试必备工具：抓包改包、重放、爆破、漏洞扫描。

版本 说明 下载
Community（免费） 社区版，含代理/Repeater/Intruder 基础功能 PortSwigger 官网
Professional（付费） 专业版，扫描器 + 更多扩展 PortSwigger 官网

核心模块：Proxy（抓包）→ Repeater（重放）→ Intruder（爆破）→ Decoder（编码解码）

快速上手

实战案例见 ctf-web 题解；抓包配置见 Burp CA 证书与 HTTPS 抓包。

OWASP ZAP

免费开源的 Web 应用安全扫描器，Burp 的替代方案。

说明 下载
开源免费，支持主动/被动扫描 官网下载

🔭 信息收集与扫描

Nmap

端口扫描与服务发现的事实标准。

下载：nmap.org（Windows / Linux / macOS 全平台）

SQLMap

SQL 注入自动化检测与利用工具（Python，开源）。

下载：github.com/sqlmapproject/sqlmap

Hydra

在线口令爆破工具，支持 SSH/FTP/HTTP 表单等几十种协议。

下载：GitHub thc-hydra（Kali 自带 hydra）

Xray

长亭出品的被动扫描器：流量经过即可自动检测漏洞，社区版免费。

说明 下载
社区版免费，配合 Burp 被动扫描 GitHub Releases / 国内下载

AWVS（Acunetix）

商业级 Web 漏洞扫描器，自动爬取 + 深度扫描，提供 14 天试用。

下载：Acunetix 官网（试用版免费）

Nessus

系统与网络漏洞扫描器，覆盖主机/中间件/Web 多层面。

下载：Nessus Essentials 免费版

🌐 流量分析

Wireshark

网络抓包分析工具，取证与排障必备。

下载：wireshark.org（全平台免费开源）

常用过滤

取证场景完整教程见 数字取证。

🔬 逆向与二进制

Ghidra

NSA 开源的逆向分析套件，功能对标 IDA，免费。

下载：GitHub Releases（需 JDK 21）

特点：反编译伪代码、脚本化（Python/Java）、跨平台。

IDA Free

Hex-Rays 出品的免费版反汇编器（支持 x86/x64/ARM 等）。

下载：Hex-Rays IDA Free（免费，专业版需购买）

gdb + pwndbg

Linux 动态调试组合，Pwn 题调试利器。

安装：Kali 自带 gdb；pwndbg 见 GitHub
