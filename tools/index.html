安全工具与技能

Burp Suite

Burp Suite 是 Web 安全测试中最常用的抓包改包工具，我在 CTF 和日常练习中主要使用以下功能：

抓包与改包

  • 设置浏览器代理，拦截 HTTP/HTTPS 请求
  • 修改请求头、请求参数、Cookie 等字段
  • 结合 Repeater 模块进行重放攻击测试

典型场景

  • 修改 User-Agent 绕过服务端校验
  • 修改 Referer、X-Forwarded-For 等请求头
  • 拦截表单提交，修改隐藏字段或前端校验参数

操作流程

详细实战案例见 ctf-web 题解

Nmap

Nmap 用于网络扫描与服务发现，是渗透测试信息收集阶段的核心工具。

常用命令

学习进度

  • 掌握 SYN 扫描、TCP 连接扫描原理
  • 能识别常见开放端口与服务（22 SSH、80 HTTP、443 HTTPS 等）
  • 能结合端口信息初步判断机器角色

Wireshark

Wireshark 用于网络流量抓包与分析，在 CTF 取证题和网络排障中非常实用。

常用功能

  • 设置过滤条件（http、tcp.port==80、ip.addr==x.x.x.x）
  • 跟踪 TCP 流 / HTTP 流
  • 导出 HTTP 对象（文件、图片等）
  • 分析 TLS 握手过程

CTF 中的应用

  • 从流量包中提取敏感文件
  • 分析攻击者的请求路径
  • 还原通信过程

Docker

Docker 用于快速搭建各类漏洞靶场和测试环境。

常用操作

已搭建过的靶场

  • DVWA（Damn Vulnerable Web Application）
  • Upload-labs 文件上传靶场
  • SQLi-labs SQL 注入靶场

编码与密码工具

日常 CTF 解题中，我使用 Python 编写了以下工具脚本（已开源至 GitHub）：

  • XOR 爆破器 — 自动尝试 256 种密钥，输出可打印结果
  • 递进凯撒解码器 — 处理偏移量递增的凯撒密码变种
  • Base 家族识别器 — 自动判断 Base64 / Base32 / Base58 并解码

这些脚本已归档至 Security-Scripts
