📌 刷题方法论

CTF 通用五步：

  1. 信息收集：看附件类型（file）、看页面源码（F12）、看响应头
  2. 识别考点：编码特征（Base64/Hex/ROT13）→ 漏洞类型（注入/上传/反序列化）→ 加密算法（RSA/AES/古典）
  3. 工具先行：binwalk / strings / xxd / Burp Suite / IDA / Ghidra / pwntools
  4. 逆向推理：加密题从外层往内层剥，前端校验题在 JS 里找硬编码密文
  5. 沉淀脚本：赛后把解题过程写成 Python 脚本，归档复用
